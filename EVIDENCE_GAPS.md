# Evidence gaps blocking stronger claims (2026-09-14)

These gaps are carried forward as explicit boundaries. No new experiment is started by this writing pass.

| Gap | Minimal validation needed | Affected wording |
|---|---|---|
| Stable real-population complementarity versus repeated same-code sampling | Balanced real population, same-code clone controls, cache-on/off conditions, interleaved scheduling, independent repeats, and a pre-specified repeat-stable estimand | Cannot claim stable additional capability or that observed headroom is mechanism complementarity. |
| Cost comparability | Pre-request solver-call/token/latency budget with identical stopping and failure rules; report realized usage and unknown/pending states | Cannot call arms equal-compute or claim deployment cost benefit. |
| Pure conformance effect | Complete legal-strategy gate contract and independent calibration on the same frozen raw pool, including prompt-level transformations | The archived D-A result is a combined strategy/screening/conformance contrast. |
| Old/new protocol bridge | Hold target, builders, tasks, judge, cache, and execution fixed while changing only the protocol component | Phase-I non-recurrence in Phase II does not identify its cause. |
| Independent selector utility | Freeze a selector on development data, evaluate on new tasks/batches, and compare random, top-accuracy, same-code-repeat, bare, best-fixed, and cost | W1 headroom change is descriptive and is not a routing gain. |
| Gate instrument clearance | Fresh independent controls with complete response-interface coverage and a prespecified rule for unresolved cases | Finite development-control results do not establish population false-accept/false-reject rates. |
| Provider common pool | Complete the frozen pool with all requests accounted for, then freeze candidate identities before gate/benchmark scoring and reconcile cost | Partial acquisition remains provenance only. |

The current paper can report the BIRD archived measurements and the MATH-500 mini-audit with their limits. It should not use these gaps as hidden assumptions in the title, abstract, figure captions, or conclusion.
