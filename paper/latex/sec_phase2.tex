Phase II is the confirmatory study. Its protocol was frozen and committed
before any confirmatory outcome was observed (one exception, disclosed as
deviation D1 in the protocol changelog: an 18-item pipeline smoke test whose
aggregate accuracies were observed and whose items were retained); deviations are logged in the
protocol changelog (Appendix~\ref{app:phase2-protocol}). The frozen
estimand, splits, instruments, and analysis plan are summarized here.

\subsection{Design}\label{sec:p2design}

\paragraph{Arms.} Two crossed factors: \emph{strategy forcing} (S=1: the
builder is assigned a named mechanism from a fixed set of eight; S=0: the
builder invents an improvement with no mechanism named) and the
\emph{conformance gate} (G=1: the harness must pass the frozen conformance
suite; G=0: neutral validity only). This yields four factorial arms, which
we denote \textbf{II-A} (free/ungated), \textbf{II-B} (free/gated),
\textbf{II-C} (forced/ungated), \textbf{II-D} (forced/gated). A fifth,
pre-specified \emph{secondary} arm \textbf{II-E} (open mechanism discovery:
the builder emits a self-specified behavioral contract over generic trace
primitives, gated on its own declaration) tests whether mechanism diversity
requires author-supplied vocabulary at all; it is deliberately outside the
factorial. Each cell has eight slots: the eight assigned mechanisms in the
forced arms, eight independent generations of the same free prompt in the
free arms. In the gated free arm (II-B) the builder emits a self-declared
mechanism from a fixed four-word vocabulary
(\texttt{repair}, \texttt{vote}, \texttt{twostage}, \texttt{plain}); the
gate verifies the declared scenario against the trace. These declarations
are narrower than the forced contracts and the mapping is operational,
not independently calibrated (Appendix~\ref{app:gatecontrols}), so arm-B
populations are not nested in arm-A and yields need not be ordered.
These arm names are Phase-II-specific; Phase-I conditions in
\S\ref{sec:phase1probes} are always referred to with their descriptive
names.

\paragraph{Implemented treatment; common attempt cap.} The original gate maps both
\texttt{hint\_guard} and \texttt{format\_guard} to a plain scenario that
returns \texttt{NO\_MECHANISM\_declared}; admission requires \texttt{PASS}.
Thus two of eight forced strategy slots cannot pass even if neutrally
valid, and no \texttt{format\_guard} candidate passed neutral validity in
either forced arm (an extraction audit finds embedded SQL fences can
truncate otherwise valid Python, Appendix~\ref{app:extraction}). We
interpret G as \emph{nontrivial-mechanism screening plus conformance
verification}; the archived results do not identify pure verification.
Each slot has at most $R{=}3$ raw builder attempts (same model,
temperature 0.7, 16{,}384 token cap), stopping at first acceptance;
logged raw attempts total 269/255/273/324 for A/B/C/D, and token costs
are not fully recovered. Slot failure is final (no top-up), so
generation reliability is part of the treatment and is reported
separately via three rates (Appendix~\ref{app:phase2-protocol}).

\paragraph{Builders and seeds.} Six builders from independent labs
(GLM-5.3, Qwen3.8-Max, DeepSeek-V4-Pro, Kimi-K3, MiniMax-M3,
ERNIE-5.0-Thinking-Preview), three seeds each: 18 paired (builder $\times$
seed) cells --- the strongest models on the project's single API gateway; no
Anthropic- or OpenAI-family builder was accessible, so frontier
capability-dependence is untested. Every cell enters the primary contrast
regardless of admitted population size, including $K{=}0$; excluding
low-yield cells would condition on a post-treatment outcome.

\paragraph{Data isolation.} A fail-closed contamination registry scans every
project artifact for observed BIRD questions. Two databases touched during
development are banned wholesale; the confirmatory evaluation uses
\textbf{1{,}169 questions from nine databases never opened during
development}, with a stratified 400-item core drawn pre-outcome
(proportional allocation across the nine databases, seed 20260904; no
outcome variable used; no pretraining-time isolation claimed; the 18-item
smoke contact is the disclosed exception). Factorial secondary
analyses run on the same core items for all four arms.

\paragraph{Judge.} Primary: the official BIRD execution scorer (set
equality on raw result rows, 30\,s wall-clock timeout). Secondary: the
Phase-I legacy judge, measured to be uniformly conservative (on Phase-I
matrices it never credits an answer the official scorer rejects).

\paragraph{Instruments.} The conformance suite drives each harness against
scripted scenarios and asserts on the recorded execution trace, never on
task performance, so gating cannot leak outcome supervision. Every
mechanism is probed with \emph{paired counterfactual variants} whose
correct answers differ --- including a variant where the first query
\emph{succeeds}, separating conditional repair from an unconditional
second call. Calibrated against hand-written positive/negative controls
and re-run before each generation batch (Figure~\ref{fig:design},
Appendix~\ref{app:phase2-protocol}).

\subsection{Frozen analysis plan}\label{sec:p2plan}
The \textbf{primary estimand} is the paired difference in bare-inclusive oracle
headroom, $H(\text{II-D}) - H(\text{II-A})$ over (builder $\times$ seed) cells, on
the full 1{,}169-question set under the official judge --- a continuous effect with
a two-sided 95\% CI and paired permutation test, never a pass/fail threshold.
The diagonal contrast is primary because the two factors are deployed
together in the generation pipeline; main effects and interaction
decompose it as secondaries. The
Phase-I thresholds survive only as a descriptive checklist.
\textbf{Confirmatory secondaries} (Holm-corrected, all four arms on the same
core-400 items): gate main effect $[(B{-}A)+(D{-}C)]/2$, strategy main effect
$[(C{-}A)+(D{-}B)]/2$, and their interaction $(D{-}C)-(B{-}A)$ --- whether strategy
differentiation requires execution fidelity to be realized.
\textbf{Original plan and corrected inference}: the original code omitted
within-database task resampling and resampled cell summaries only. The
versioned post-review analysis uses 10{,}000 shared database/within-database
task draws across all arms and cells, keeping builders fixed and resampling
generation seeds within builder; it does not add execution-repeat variance,
and with only three seeds per builder the seed component may understate
true generation variability (a reported data limit).
Exact sign-flip reference tests are conditional on observed tasks and on
cell-contrast sign symmetry (one-sided primary; two-sided secondaries with
Holm adjustment) --- not randomized causal tests. $H(P)$ is \emph{not}
monotone in $K$ --- adding a harness that answers everything correctly
drives headroom to zero --- so matched-$K$ comparison, not monotonicity,
licenses cross-population claims. K-matched sensitivity, full estimand
definitions, and the robustness audits (dual judge, cache-off replication,
repeat stability) are specified in Appendix~\ref{app:phase2-protocol}
together with the protocol deviation log.
