\subsection{MATH population, common analysis set, and coverage}\label{app:crossdomain}
The single-run study supplies the initial coverage evidence and the
programs for the repeat panel. It carries the BIRD admission study's
free, ungated generation procedure into competition mathematics, with
a domain-specific answer comparator.

\paragraph{Protocol and analysis set.}
\label{app:builder-instruction}
The builder task can be summarized as follows (a structured summary,
not a verbatim prompt): write a Python harness implementing
\texttt{solve(question)}; use \texttt{self.llm} to improve on a single
greedy call; choose the prompting, decoding, sampling, and control flow;
return the final mathematical answer with the requested
\texttt{\#\#\#\#} marker. Gold answers belong to the external judge.
No slot is assigned a mechanism and no cross-program diversity target
is imposed. Repeated attempts use the same instruction, without
earlier candidate code or performance feedback. Admission checks
interface validity and nonempty output, not an accuracy improvement.

Six builders receive eight slots each under one seed, with at most
three raw attempts per slot. The neutral-validity gate checks parsing,
import, interface, and nonempty answers on two development questions. The frozen target is
GLM-5.3-Flash, with member-specific decoding and temperature $0$ for
\bare{}. The original task split precedes generation and reserves
$100$ development problems. The final evaluation analysis uses the
same $\RcvPairedN$ fully observed tasks for the single-run population,
both repeat arms, and frozen-policy scoring. This task set is determined
after collection by completeness; $\RcvExcludedN$ incomplete problems
are excluded (Appendix~\ref{app:wp1r}). The development tasks and frozen
selector remain unchanged.

The judge compares numeric values when both sides parse as numbers
(including fractions and decimals), and normalized LaTeX otherwise.
Normalization strips units, base subscripts, and degree symbols,
preserves text-command content, and maps matrices to tuples. The
requested final-answer marker is \texttt{\#\#\#\#}. Formatting each gold
answer with this marker gives $\RcvPairedN/\RcvPairedN$ correct
self-comparisons, verifying format consistency on these gold answers. The observed single-run baseline accuracy is
$\RevisionMathBest\%$ on the analysis set.

The validity gate admits $35/48$ slots. The two reasoning-heavy
builders, GLM-5.3 and Qwen3.8-Max, exhaust the $32$k-token generation
budget before emitting code in most slots. This under-represents those
builder styles under the fixed generation budget. The exploratory
study evaluates free generation with neutral-validity admission under
one seed.

\paragraph{Results on the common complete set.}
All $36$ members, including \bare{}, have one recorded score on each
of the $\RcvPairedN$ tasks ($\RcvSingleCells/\RcvSingleCells$ cells).
Mean pairwise disagreement is $\RevisionMathDisagreement\%$
(maximum $\MathMaxDisagreement\%$). There are $\MathUnique/36$ unique
member outcome vectors ($\MathGenUnique/35$ generated vectors), and
$\MathIdenticalPairs\%$ of member pairs have identical outcomes.
The union of generated candidates repairs $\MathUnionRepair\%$ of
baseline errors and fails on $\MathUnionFail\%$ of baseline-correct
problems. The latter measures the fraction of baseline-correct tasks
on which all generated members fail.
Oracle coverage is $\RevisionMathOracle\%$, versus
$\RevisionMathBest\%$ for the best fixed member, \bare{}, giving
$\RevisionMathHeadroom$ percentage points of headroom. Generated-member
accuracies range from $\MathGenMin\%$ to $\MathGenMax\%$.

The fresh repeat panel uses eight generated members plus \bare{}
and nine same-code slots on these identical task identities. Its
clone-adjusted diagnostic measures held-out selection gain for this
panel; the one-run headroom characterizes the full generated population. Replaying the archived
judge reproduces all $\RcvSingleCells$ included scores; the versioned
endpoint-sensitive judge produces identical scores on this subset.


\paragraph{Scope.}
The MATH findings characterize exploratory generation under one seed
and one target on a completeness-selected evaluation set. The BIRD
studies characterize SQL execution and admission under their respective
protocols.
