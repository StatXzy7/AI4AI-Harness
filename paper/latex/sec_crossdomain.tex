\section{Cross-Domain Replication: MATH-500 Mini-Audit}\label{app:crossdomain}

To test whether the Phase-II clean-protocol finding (free ungated generation
produces distinct one-run correctness vectors) is
text-to-SQL-specific, we replicated the free-arm protocol on competition
math.

\paragraph{Protocol.} Six builders (the same models as Phase II), one seed,
eight slots each, an $R{=}3$ raw-attempt cap per slot, neutral validity gate
(mechanism-blind: parse, import, interface, non-empty answer on two dev
questions). Frozen target GLM-5.3-Flash (same as the SQL study), temperature
0. MATH-500 \citep{math500}: 500 tasks frozen before generation (100 dev /
400 eval, seed 20260908). The 100 dev tasks are used only for
generation-side smoke tests and are never executed in the evaluation
archive; the selection-policy experiments of
Appendix~\ref{app:diagnostics} therefore carve their training split (80
tasks) from the eval side, leaving 320 scored tasks for D/E claims. Judge: numeric equality where both sides parse as
numbers (including $a/b$, \verb|\frac{a}{b}|, decimals), else normalized
LaTeX string equality (units, base subscripts, $^\circ$ stripped;
\verb|\text{X}| content preserved; pmatrix $\to$ tuple). Judge
self-consistency: 400/400 gold answers judge correct against themselves.
bare accuracy 0.9375 under the matched answer-format instruction. Yield:
35/48 slots admitted ($R_{\mathrm{artifact}}$ 0.10--1.00; the two
reasoning-heavy builders, GLM-5.3 and Qwen3.8-Max, exhausted the 32k-token
generation budget on reasoning before emitting code in most slots ---
reported as-is). This constraint effectively removes two of the six
builders from the evaluated pool, so the free-arm population
under-represents reasoning-heavy builder styles; we do not adjust the
budget post hoc, and the limitation is part of the reported protocol. This is a replication probe, not a factorial: no
strategy forcing, no conformance gate.

\paragraph{Results (35 harnesses, 400 eval tasks).} Mean pairwise outcome
disagreement 10.6\% (max 33.0\%); 33 of the 36 members had unique outcome
vectors when bare is counted (32 of the 35 generated harnesses);
outcome-identical pairs 0.7\% --- no trace of
Phase-I-style collapse. Union repair 76.0\% of bare errors; the union of all
generated candidates fails on 0.8\% of bare-correct tasks (a
\emph{union-all-fail} rate, not an any-candidate or router harm). Observed
oracle coverage exceeds bare by 4.75\,pp, and the best fixed member is
\emph{bare itself} (0.9375; generated harnesses 0.6825--0.915): every
generated member is worse individually. The one-run mini-audit originally
did not collect repeated-execution or same-code clone controls; that gap is
closed on this same MATH-500 task set by the fresh pre-registered WP-1R
collection (\S\ref{sec:f3-clones}), which executes an eight-member panel and nine
same-code clone slots for three independent repeats and therefore does
evaluate the stability estimands cross-domain. A
hash-bound re-execution of the versioned endpoint-sensitive rescore of all
14{,}400 archived verdicts changes 14 of them (0.097\%): all are v1 false
rejects of interval-endpoint answers on a single task, so per-member
accuracies rise by at most one task and no qualitative conclusion moves
(Appendix~\ref{app:diagnostics}). An earlier stored artifact reporting zero flips is
not reproducible from the committed code and is retained only as provenance.

\paragraph{Two failure-side observations.} First, the clean-protocol
diversity result replicates in a second domain with a different output
space. Second, a quarantined pilot round (disclosed in
\texttt{PROTOCOL\_CHANGELOG.md}, entry G1) supplies an exploratory comparison:
when the same six builders were (mistakenly) given a GSM8K-style task
description whose numeric answer format did not match MATH-500, the
generated population remained behaviorally diverse (16.2\% disagreement,
19 unique outcome vectors) while its union repair collapsed to 18\% --- and
code-level inspection of the catastrophic members reproduced the Phase-I
trace taxonomy verbatim (a generate-then-verify harness whose verifier
rejected nearly every answer and whose fallback returned the stale loop
variable or ``0''). Diversity without utility, induced by a prompt-side
protocol error invisible to code-level checks: the measurement mandate, not
any code-level audit, is what detects it.

\paragraph{Scope.} One seed, one target, no factorial, exploratory; the
Phase-I collapse-inducing SQL protocol was not re-run in the math domain,
so this replication speaks to the clean-protocol result only, not to the
boundary of collapse.
