\subsection{Models and versions}\label{app:models}

Table~\ref{tab:models} lists the models used in the reported benchmark
studies with their exact version strings as sent to the API. All models were accessed through a single
commercial OpenAI-compatible API aggregator (the same provider for every
role). The frozen
target model identity is fixed; decoding follows each harness, with
temperature $0$ for the single-call baseline. Phase-II harness generation uses
temperature 0.7 with a 16{,}384-token budget. Phase-I generation
conditions and their evidence gaps are described in
Appendix~\ref{app:phase1-provenance}. Phase I used a proxy execution judge;
Phase II uses the official BIRD scorer (30\,s timeout), with the legacy
judge as a secondary audit. The MATH-500 probe uses the answer comparator
in Appendix~\ref{app:crossdomain}; no LLM judge produces reported accuracy.
