\subsection{Models and versions}\label{app:models}

Table~\ref{tab:models} gives the exact API model identifiers. All roles
use one commercial OpenAI-compatible aggregator. Target identity is fixed;
decoding follows each harness, with temperature $0$ for the single-call
baseline. Phase-II generation uses temperature 0.7 and a 16{,}384-token
budget; Phase-I conditions appear in Appendix~\ref{app:phase1-provenance}.
Phase I uses a proxy execution judge, Phase II the official BIRD scorer
(30\,s timeout) with a secondary legacy-judge audit, and MATH-500 the
answer comparator in Appendix~\ref{app:crossdomain}. Reported accuracy
uses no LLM judge.
