A harness population can find more answers, exhibit repeatable
differences, and still provide little value to a selector. The tested
MATH panel brings these properties into the same comparison: identical
programs produce positive oracle headroom, generated score patterns
repeat mainly through persistent losses, and the frozen selector gains
$\RcvPolicyGain$ pp. At 27 executions, both arms reach
$\RcvReplayFullCoverage\%$ oracle coverage. These findings make the
resource-allocation question concrete. The value of more programs lies
in task advantages that persist, guide selection, and improve on
additional executions of a fixed program.
