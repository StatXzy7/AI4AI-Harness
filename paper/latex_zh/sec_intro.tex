固定的推理预算应该用于生成更多程序，还是让同一个程序执行更多次？自动化智能体设计使前一种选择更容易实现：构建器生成一组 LLM harness，每个程序为冻结的求解模型安排提示、工具与控制流 \citep{adas2024,tthe2026,selfharness2026}。其吸引力在于，不同程序可能分别擅长不同任务。但要作出这种解释，就必须把群体收益与评估群体时增加的尝试次数区分开。

困难在于，观测到不同的成功并不要求存在不同的能力。一个成功概率为 $0.5$ 的程序独立执行两次，就能以 $0.75$ 的概率覆盖一道题，尽管没有引入任何程序专长。Pass@$k$ 与自一致性已利用额外采样的价值 \citep{chen2021codex,selfconsistency2022,moreagents2024}。因此，即使每个成员代码相同，一个看到全部结果后才挑选正确答案的 oracle 也能显示群体收益。对少数重复取平均并不会自动消除这种歧义：选择最大的估计成功率，也会偏向有利的采样波动。

本文研究，什么证据能够区分覆盖机会与任务专长。全文围绕三个问题展开：已记录的执行是否包含额外正确答案？某个成员在一道题上的优势能否在新执行中保持？一个规则能否在看到答案前作出有用选择，并优于把同等资源交给固定程序？这三个问题对应不同的量，第一个问题的肯定答案不能代替后两个问题的答案。

我们先报告全部 $35$ 个生成程序在 MATH-500 上的单次覆盖，再在所选子集上检验专长解释。核心对照固定群体规模，只改变程序是否不同：八个生成 harness 加上 \bare{}，对照九个逐字节相同的基线槽位。每个成员进行三次新执行，用其中两次发现逐任务选择，再用第三次验证。同代码臂测量这套过程在没有程序专长时会报告什么。随后，在同一面板上冻结于开发任务的选择器检验题目特征能否支持选择，等执行次数的 oracle 重放则比较可获得覆盖。最后，BIRD 轨迹补充检查源码差异是否真正进入执行。它提供独立诊断，不是 MATH 比较结果的因果解释。

证据带来三项认识。\textbf{第一}，同代码对照也产生正的重复平均 oracle 估计，说明这一信号本身不能识别程序专长。\textbf{第二}，留出重复与校准明确了当前数据的判断边界：克隆校正均值为 $\WpVthreeD$\,\%，但缺失与有限功效使稳定专长尚未判清。\textbf{第三}，把选择与覆盖分开，会改变实际价值的判断：所测选择器收益为 $\WpPiZDiff$\,\%，而完整执行预算下的重放，其观测 oracle 均值更有利于增加单次调用的执行次数。这些发现将覆盖、重复证据与实际选择分开。
