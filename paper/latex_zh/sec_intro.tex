在冻结的 LLM 上增长最快的杠杆已不再是权重，而是 \emph{harness}（脚手架）——即为任务包裹模型的那段由提示、工具与控制流组成的程序。一系列不断增长的 ``AI4AI'' 系统自动生成这类脚手架：LLM 构建器提出、编辑并演化 harness 代码。其隐含前提是：当代码不同时，\emph{行为}也不同——三十个 harness 组成的群体应当是三十种作答方式，而不是同一种方式被写了三十遍。在此类群体上做路由与价值预测，预设的正是这一点。

\textbf{Phase I（发现性研究）：前提不成立，且原因可辨识。}在冻结中端目标模型的 BIRD text-to-SQL \citep{bird2021} 上，我们测量的是一个标准 harness 演化循环产出的候选实际\emph{做了什么}，而非其源文件声称什么（图~\ref{fig:phenomenon}）。每个候选都通过了代码差异检查，然而在 12 个生成候选（66 个候选对）中，两两结果分歧平均仅为 \textbf{3.8\%}，且 \textbf{21 对在行为上完全相同}；若把随系统交付的 \react{} harness 和 \bare{} 基线也计入（91 对），则有 36 对在每个任务上返回完全相同的正确性，且两两代码相似度与结果分歧之间没有观测到的秩关联（Spearman $\rho=-0.01$）。交付的 \react{} 变体在每个被审计的任务上都与 \bare{} 逐字节复现相同的最终 SQL。执行轨迹审计把``不同的代码''分解为三类失败：机制被\emph{描述}却不在控制流中执行、反馈对输出没有因果通路、以及真正意义上的多轮路径被损坏（\S\ref{sec:phase1}）。我们称之为\textbf{行为坍缩}（behavioral collapse）。

坍缩并不是任务本身的属性：四个手写的、执行路径被强制区分的 harness 在同一目标与判分器上给出 7.3\,pp 的 oracle headroom——路由所需要的提升空间是真实存在的；是生成侧未能把它填充起来。我们还在一条已部署的管线中记录到第二种更原始的失败模式：一个被广泛使用的优化循环产出了\emph{与基线源码逐字节相同}的候选。这并非行为坍缩——根本没有生成出任何不同的群体——我们将其报告为\emph{生成空}（generation-null，M0）失败，并将其与坍缩论断严格区分开；坍缩论断只建立在源码确实不同的群体之上。

\textbf{Phase II（确证性研究）：一个预先指定的因子设计。}Phase I 表明行为坍缩或许可以通过生成侧干预修复，但其设计——两个嵌套对比、三个构建器、早期运行未留日志——无法把协议效应与构建器效应分开，其评估集与开发条目重叠，且其判分器是一个保守的代理。因此，在任何确证性结果被观测之前，我们先冻结了一份确证性协议：一个 $2{\times}2$ 因子设计，交叉\emph{策略强制}（指定机制 vs.\ 自由发明）与\emph{机制一致性门控}（反事实轨迹验证 vs.\ 仅中立有效性检查），再与六个构建器模型和三个种子交叉，在开发期间从未打开过的九个数据库中抽取的 1{,}169 道题上评估，由官方 BIRD 判分器打分，主对比（forced+gated vs.\ free+ungated 群体）作为成对连续效应分析并给出分层 bootstrap 置信区间（\S\ref{sec:phase2}）。一致性测量工具在任何候选被评分之前，先在手写正控制与已知负样本（冒名顶替的 harness）上校准。

确证性答案两次改写了叙事：Phase-I 的坍缩在干净协议下没有复现（自由生成本身就 headroom 丰富），而干预本身在测量精度之内为零结果——表面上的负门控效应在很大程度上受规模混淆且未过 Holm 显著性，且 API 非确定性噪声底超过了所讨论的亚 pp 级效应（第~\ref{sec:results}~节）。

我们的贡献：
\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{对 AI 生成 harness 群体行为坍缩的结果矩阵测量}，并附一套解释代码多样性为何未能转化为行为多样性的执行轨迹分类法，以及对真坍缩与生成空失败的干净区分。
\item
  \textbf{经过校准的生成侧测量工具与一项预先指定的因子研究}：一套反事实一致性测试套件与自指定行为契约，二者均在正负控制上校准；一个各臂原始生成预算相等的 $2{\times}2$ 设计，在无污染数据上、以官方评分器分离联合干预及其各组分的效应。
\item
  \textbf{一个关于路由的边界结果}：在 Phase-I 群体上，开集 harness 价值预测无法胜过最优固定 harness，其表面上的逐任务信号与任务记忆一致；我们将其精确限定在所测的预测器与划分上（\S\ref{sec:boundary}）。
\end{enumerate}

在 harness 之外，我们所分离出的这一失败模式——LLM 构建器产出貌似合理、文档完善、却在行为上惰性的变体——是一种生成可靠性现象，我们预期凡是要模型修改自身程序之处，它都会再次出现。
