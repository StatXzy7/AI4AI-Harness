\subsection{执行前选择与 oracle 重放}\label{sec:utility}
\paragraph{执行前选择没有获得额外收益。}
冻结的特征策略检验一种执行前实际可作出的选择。在重复面板上，它对全部 $400$ 个评估任务选择 \bare{}，与开发集选定的固定成员同为 $\WpPiZAcc\%$ 重复平均准确率，收益为 $\WpPiZDiff$\,\%。预先固定的随机成员比较对象差值为 $\WpRandomDiff$\,\%（附录~\ref{app:selection}）。该策略避开了弱成员，却没有获得任务专属收益。这个结果只涉及一个策略与特征集，既未穷尽可能的选择器，也没有把 oracle 机会变成实际准确率。

\paragraph{等执行次数的 oracle 重放。}
\label{sec:selection-result}
即使考察 oracle 覆盖，也需要与固定程序可以获得的额外尝试比较。重放为开发集排序的面板组合与克隆臂分配相同的 harness 执行次数 $b$。在 $b=3$ 时，面板仅含 \bare{}，因此 $+0.37$\,\% 的差异不可能来自程序多样性。增加成员后，$b=9$ 时差值为 $+0.03$\,\%，$b=15$ 和 $27$ 时为负（表~\ref{tab:execution-means}）。

生成臂的采集成本也更高：$22{,}192$ 次逻辑调用与 $54.17$M 已知 token，对照克隆臂的 $10{,}800$ 次调用与 $14.51$M token，token 比为 $3.73\times$。这些是实际采集支出，不是等 token 性能比较。由于答案格式不兼容，本文不报告跨臂多数投票。因此，所测选择器没有提供收益，而等执行次数的 oracle 均值没有显示该组合持续占优。两项结果都未确立其他选择器或等 token 的实际运行比较将会如何表现。
