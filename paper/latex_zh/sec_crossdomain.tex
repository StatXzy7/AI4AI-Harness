\subsection{MATH 群体、共同分析集与覆盖}\label{app:crossdomain}
单次研究提供覆盖测量与重复面板的程序来源，将 BIRD 的无门控自由生成方案用于竞赛数学，并采用领域特定比较器。

\paragraph{协议与分析集。}
\label{app:builder-instruction}
构建器指令可概括为（非逐字引用）：编写 Python \texttt{solve(question)} harness，通过 \texttt{self.llm} 改进单次贪心调用，自选提示、解码、采样与控制流，以 \texttt{\#\#\#\#} 返回最终答案。标准答案保留在外部评分器中。槽位不分配机制或多样性目标；尝试沿用相同指令，不提供先前代码或性能反馈。准入要求接口有效且输出非空。

六个构建器在一个种子下各获八个槽位，每槽至多三次尝试，在两道开发题上检查解析、导入、接口及非空答案。目标为 GLM-5.3-Flash，解码由成员定义，\bare{} 温度为 $0$。生成前划分保留 $100$ 道开发题。单次、重复与选择策略分析共用 $\RcvPairedN$ 道完整观测题；采集后的完整性规则排除 $\RcvExcludedN$ 道题（附录~\ref{app:wp1r}）。开发题与选择器保持固定。

评分器优先比较可解析的数值（含分数与小数），否则比较规范化 LaTeX。归一化去除单位、进制下标和度数符号，保留文本命令内容，并将矩阵转为元组。加上 \texttt{\#\#\#\#} 标记的标准答案通过 $\RcvPairedN/\RcvPairedN$ 次自比较。该集单次基线准确率为 $\RevisionMathBest\%$。

门控接纳 $35/48$ 个槽位。GLM-5.3 与 Qwen3.8-Max 在多数槽位发出代码前耗尽 $32$k token 预算，使其风格在这一固定预算群体中代表性不足。

\paragraph{共同完整集上的结果。}
包含 \bare{} 的 $36$ 个成员在 $\RcvPairedN$ 题上各有一次评分，共 $\RcvSingleCells/\RcvSingleCells$ 个单元。平均成对分歧为 $\RevisionMathDisagreement\%$（最大 $\MathMaxDisagreement\%$），唯一结果向量为 $\MathUnique/36$（生成为 $\MathGenUnique/35$），$\MathIdenticalPairs\%$ 的成员对结果相同。生成并集修复 $\MathUnionRepair\%$ 的基线错题；在 $\MathUnionFail\%$ 的基线正确题上，所有生成成员均失败。Oracle 覆盖 $\RevisionMathOracle\%$，比最佳固定成员 \bare{}（$\RevisionMathBest\%$）高 $\RevisionMathHeadroom$\,pp。生成成员准确率为 $\MathGenMin\%$--$\MathGenMax\%$。

重复面板在相同题目上比较八个生成成员加 \bare{} 与九个同代码槽位。留出诊断对应此面板，单次余量对应完整群体。存档评分器与版本化端点敏感评分器均复现全部 $\RcvSingleCells$ 个纳入评分。

\paragraph{范围。}
这些测量对应一个种子、一个目标与按完整性筛选的 MATH 题集；BIRD 使用下文的独立协议。
