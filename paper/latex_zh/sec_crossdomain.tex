\section{跨领域重复：MATH-500 小型审核}\label{app:crossdomain}
为检查 Phase-II 调整协议下的观察（无门控自由生成产生不同的单次正确性向量）是否仅限文本转 SQL，我们在竞赛数学上重复自由组协议。
\paragraph{协议。}六构建器与 Phase II 相同，单个种子，每个八槽位，每槽位最多三次原始尝试；中性有效性门控不检查机制，只检查解析、导入、接口以及两道开发题上答案非空。冻结目标为 GLM-5.3-Flash，温度 0。MATH-500 \citep{math500} 的 500 题在生成前冻结为 100 开发／400 评估，种子 20260908。若两侧均可解析为数值，评分使用数值相等（含 $a/b$、\verb|\frac{a}{b}|、小数）；否则使用归一化 LaTeX 字符串相等，去掉单位、进制下标与 $^\circ$，保留 \verb|\text{X}| 内容，将 pmatrix 转为元组。评分器自一致性检查中，400/400 标准答案与自身比较均判对。匹配答案格式指令下 bare 准确率为 0.938。48 槽位中接纳 35 个，各构建器 $R_{\mathrm{artifact}}$ 为 0.10--1.00；GLM-5.3 和 Qwen3.8-Max 在多数槽位输出代码前已将 32k token 生成预算耗于推理，按实际情况报告。本项是重复探查，不是析因实验，没有策略强制或一致性门控。
\paragraph{结果：35 个 harness、400 道评估题。}平均成对结果分歧为 10.6\%（最大 33.0\%），$K_{\mathrm{eff}}=33/35$（0.94），结果完全相同的 pair 占 0.7\%，未出现 Phase-I 式的坍缩模式。联合修复为 bare 错题的 76.0\%，联合损害为 0.8\%，相对 bare 的 oracle 提升空间为 4.75 个百分点。但最佳固定成员恰好是 bare 自身（0.9375，生成成员为 0.68--0.87）：观测 oracle 覆盖超过 bare，而每个生成成员单独均更差。未采集重复执行及同代码克隆控制，不能确立稳定互补性或可部署效用。
\paragraph{两项失败侧观察。}第一，调整协议下的观测多样性在另一输出空间的领域再次出现。第二，已隔离的试运行（\texttt{PROTOCOL\_CHANGELOG.md} 的 G1）提供探索性比较：相同六构建器被错误地给予 GSM8K 风格任务描述，数值答案格式与 MATH-500 不匹配，种群仍有行为多样性（分歧 16.2\%，$K_{\mathrm{eff}}=19/19$），但联合修复降至 18\%。对灾难性成员的代码检查发现与 Phase-I 轨迹分类一致的失败：一个先生成再验证的 harness 几乎拒绝所有答案，回退却返回过时循环变量或 ``0''。提示侧协议错误可能留下多样性却损害效用；仅有代码差异检查无法揭示这种结果。
\paragraph{范围。}单种子、单目标、无析因，属于探索性研究。未在数学领域重跑造成 Phase-I 坍缩的 SQL 旧协议，因此这里只涉及调整后协议的观察，不识别坍缩的边界。
