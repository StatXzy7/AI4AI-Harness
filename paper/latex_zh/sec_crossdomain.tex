\subsection{探索性 MATH 群体、划分与覆盖}\label{app:crossdomain}

该单次研究建立了正文的起始覆盖现象，也是重复面板的程序来源。它沿用 BIRD 准入研究的无门控自由生成方案，但使用数学任务和答案比较器。

\paragraph{协议。}六个构建器（与 BIRD 准入研究相同模型），一个种子，各八个槽位，每槽位 $R{=}3$ 次原始尝试上限，中性有效性门控（机制盲：在两道开发题上检查解析、导入、接口与非空答案）。冻结目标 GLM-5.3-Flash（与 SQL 研究相同），解码设置由各冻结成员定义；基线温度为 $0$。MATH-500 \citep{math500}：500 道题在生成前冻结（100 开发／400 评估，固定随机划分）。100 道开发题仅用于生成侧冒烟测试，从不在评估存档中执行；因此附录~\ref{app:archive-analysis} 的选择政策实验从评估侧切出其训练划分（80 道题），留下 320 道计分题供 D/E 命题。这是旧档案分析；新的重复研究在 100 道开发题上拟合选择器，并在全部 400 道评估题上评分（附录~\ref{app:selection}）。评分器：两侧均解析为数字时取数值相等（含 $a/b$、\verb|\frac{a}{b}|、小数），否则取归一化 LaTeX 字符串相等（去除单位、进制下标、$^\circ$；保留 \verb|\text{X}| 内容；pmatrix $\to$ 元组）。评分器自洽性：400/400 标准答案与自身比较均判对。匹配答案格式指令下 single-call 准确率为 0.9375。产出：48 槽位接纳 35 个（$R_{\mathrm{artifact}}$ 0.10--1.00；两个重推理构建器 GLM-5.3 与 Qwen3.8-Max 在多数槽位于发出代码前即耗尽 32k token 生成预算——按实际情况报告）。这一约束使被评估群体对重推理构建器风格的代表性不足；我们不在事后调整预算，该限制是所报告协议的一部分。这是重复探查，不是析因研究：无策略强制、无一致性门控。

\paragraph{结果（35 个 harness，400 道评估题）。}平均成对结果分歧 10.6\%（最大 33.0\%）；计入 single-call 时 36 个成员中 33 个有唯一结果向量（35 个生成 harness 中为 32 个）；结果相同的对占 0.7\%——没有 Phase-I 式坍缩的迹象。对 single-call 错题的联合修复为 76.0\%；全部生成候选的并集在 0.8\% 的 single-call 答对题上失败（这是\emph{并集全败}率，不是任一候选或路由器损害）。观测 oracle 覆盖超出 single-call 4.75\,\%，而最佳固定成员\emph{就是 single-call 自身}（0.9375；生成 harness 为 0.6825--0.915）：每个生成成员单独都更差。单次小型审核最初未采集重复执行或同代码克隆控制。单独的 WP-1R 采集（\S\ref{sec:f3-clones}）在同一题集上，为八个生成成员加 \bare{} 补充这些对照，与九个同代码槽各执行三次新重复。其采集协议在采集前冻结，v3 分析则在之后修订。非正的克隆校正均值和有限灵敏度，不能反过来识别完整群体单次 $4.75$\,\% 余量的来源。对全部 14{,}400 条存档判定的版本化端点敏感重评分的一次哈希绑定重执行改变了其中 14 条（0.097\%）：全部是单一任务上 v1 对区间端点答案的错误拒绝，因此逐成员准确率至多上升一道题，任何定性结论都不变（附录~\ref{app:archive-analysis}）。一个更早的、报告零翻转的已存储产物未能由修正分析复现，仅作为来源保留。

\paragraph{范围。}一个种子、一个目标、无析因、探索性；造成 Phase-I 坍缩的 SQL 协议未在数学领域重跑，因此本重复只说明干净协议的结果，不涉及坍缩的边界。
