\section{跨领域重复：MATH-500 小型审核}\label{app:crossdomain}

为检验 Phase-II 干净协议的发现（无门控自由生成产生不同的单次正确性向量）是否为文本转 SQL 所特有，我们在竞赛数学上重复了自由臂协议。

\paragraph{协议。}六个构建器（与 Phase II 相同模型），一个种子，各八个槽位，每槽位 $R{=}3$ 次原始尝试上限，中性有效性门控（机制盲：在两道开发题上检查解析、导入、接口与非空答案）。冻结目标 GLM-5.3-Flash（与 SQL 研究相同），温度 0。MATH-500 \citep{math500}：500 道题在生成前冻结（100 开发／400 评估，种子 20260908）。100 道开发题仅用于生成侧冒烟测试，从不在评估存档中执行；因此附录~\ref{app:diagnostics} 的选择政策实验从评估侧切出其训练划分（80 道题），留下 320 道计分题供 D/E 命题。评分器：两侧均解析为数字时取数值相等（含 $a/b$、\verb|\frac{a}{b}|、小数），否则取归一化 LaTeX 字符串相等（去除单位、进制下标、$^\circ$；保留 \verb|\text{X}| 内容；pmatrix $\to$ 元组）。评分器自洽性：400/400 标准答案与自身比较均判对。匹配答案格式指令下 bare 准确率为 0.9375。产出：48 槽位接纳 35 个（$R_{\mathrm{artifact}}$ 0.10--1.00；两个重推理构建器 GLM-5.3 与 Qwen3.8-Max 在多数槽位于发出代码前即耗尽 32k token 生成预算——按实际情况报告）。这一约束实际上把六个构建器中的两个移出了被评估池，因此自由臂种群对重推理构建器风格代表性不足；我们不在事后调整预算，该限制是所报告协议的一部分。这是重复探查，不是析因研究：无策略强制、无一致性门控。

\paragraph{结果（35 个 harness，400 道评估题）。}平均成对结果分歧 10.6\%（最大 33.0\%）；计入 bare 时 36 个成员中 33 个有唯一结果向量（35 个生成 harness 中为 32 个）；结果相同的对占 0.7\%——没有 Phase-I 式坍缩的迹象。对 bare 错题的联合修复为 76.0\%；全部生成候选的并集在 0.8\% 的 bare 答对题上失败（这是\emph{并集全败}率，不是任一候选或路由器损害）。观测 oracle 覆盖超出 bare 4.75\,pp，而最佳固定成员\emph{就是 bare 自身}（0.9375；生成 harness 为 0.6825--0.915）：每个生成成员单独都更差。单次小型审核最初未采集重复执行或同代码克隆控制；这一缺口由同一 MATH-500 题集上新的预注册 WP-1R 采集补上（\S\ref{sec:f3-clones}），它对一个八成员面板与九个同代码克隆槽执行三次独立重复，因此确实跨领域评估了稳定性估计目标。对全部 14{,}400 条存档判定的版本化端点敏感重评分的一次哈希绑定重执行改变了其中 14 条（0.097\%）：全部是单一任务上 v1 对区间端点答案的错误拒绝，因此逐成员准确率至多上升一道题，任何定性结论都不变（附录~\ref{app:diagnostics}）。一个更早的、报告零翻转的已存储产物无法从提交代码复现，仅作为来源保留。

\paragraph{两项失败侧观察。}第一，干净协议的多样性结果在第二个领域、不同输出空间上得到重复。第二，一个被隔离的试运行轮次（在 \texttt{PROTOCOL\_CHANGELOG.md} 的 G1 条目中披露）提供了一项探索性比较：当相同六个构建器（被错误地）收到数值答案格式与 MATH-500 不匹配的 GSM8K 风格任务描述时，生成种群仍保持行为多样（16.2\% 分歧，19 个唯一结果向量），但其联合修复坍缩至 18\%——对灾难性成员的代码级检查逐字复现了 Phase-I 轨迹分类（一个先生成后验证的 harness，其验证器拒绝几乎所有答案，其回退返回过时的循环变量或 ``0''）。有多样性而无效用，由代码级检查不可见的提示侧协议错误诱发：检测到它的是测量任务本身，而非任何代码级审核。

\paragraph{范围。}一个种子、一个目标、无析因、探索性；造成 Phase-I 坍缩的 SQL 协议未在数学领域重跑，因此本重复只说明干净协议的结果，不涉及坍缩的边界。
