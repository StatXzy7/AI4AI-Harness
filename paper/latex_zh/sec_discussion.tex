\textbf{研究表明了什么。}
群体效用是执行噪声被分离之后的稳定任务–harness 交互：oracle 在执行后问谁答对了，而路由器必须事先承诺。三项研究分离了此前单次报告混为一谈的量。在 BIRD 上，源代码多样性对行为差异没有信息量（$\rho=-0.01$，尽管通过代码差异检查仍有 $21/66$ 个相同向量），三条具名执行路径显示了不同程序在何处未能实现不同策略。在探索性 MATH-500 群体上，单次 oracle 覆盖比最佳固定成员高 $4.75$\,pp，而该成员就是 \bare{} 本身。在预注册面板上，逐字节相同的程序复现了正的重复平均插件（克隆臂上 $2.67$\,pp），而校准差为 $D=\WpVthreeD$\,pp（CI $\WpVthreeDCI$，$p=\WpVthreeP$）、等执行覆盖持平：在三次重复下，表观增益与对一个固定程序额外执行不可区分，预声明规则弃权而非称之为等效；冻结选择器没有捕获到预先固定随机成员所损失的任何差距（$\WpRandomDiff$\,pp）。

\textbf{一套报告协议。}
结果引出四条低成本做法：（i）纳入同代码克隆臂，使额外执行成为被测量的基线；（ii）采集留出的独立重复并做发现/验证切分，报告重复数与各臂缺失情况；（iii）把单次覆盖机会、重复稳定交互与执行前选择价值作为三个信息集不同的量分别报告；（iv）分别报告槽数、执行数与 token 数，任何预算匹配比较都在所声称的单位上执行。

\textbf{作用域。}
BIRD 证据覆盖一个 SQL 目标、六个构建器、三个种子（W1/W3 分析为描述性）；MATH 面板是在既往见过的任务上的低调用筛选抽取，不是未见过任务的检验。在 $R=3$ 时该判定只对强交叉有效（对 $H=17.5$\,pp 交互功效为 $0\%$），覆盖门控又独立地在 $12.5\%$ 的真实臂任务上失败，因此弃权是测量边界而非不存在的证据——更多重复是解决它的直接途径。该面板花费克隆臂 $3.73\times$ 的 token，因此成本受控的比较是等执行回放（而非已实现成本），校准是跨越 $100$ 个单元的经验性、经测试 DGP 的结果，而非解析的支配锥保证。可迁移的主张是这一测量区分及其在两个域上展示的控制；其他面板、目标与重复数是开放的扩展。
