\paragraph{自动化智能体与 harness 设计。}
ADAS 将智能体程序作为搜索空间 \citep{adas2024}。Self-Harness 从轨迹中挖掘失败，提出针对性修改，并在回归测试后保留修改 \citep{selfharness2026}；TTHE 则在评估期间利用无标签轨迹调整可执行 harness \citep{tthe2026}。其他系统改进任务适配与验证资源分配 \citep{jitagent2026,coevolve2026}，或通过验证、诊断、定位和策略演化使 harness 行为可观测、可编辑 \citep{harnesslens2026,harnessfix2026,ahe2026,gatedqd2026,handbook2026,harnessforge2026}。\citet{metaagents2025} 发现，所研究的自动设计智能体在逐题评分模式上的多样性较低。本文区分程序群体结果的两种解释：不同程序可能执行相同行为，相同程序也可能产生不同结果。轨迹检查判断所提机制是否实际执行；同代码重复对照则隔离不改变程序即可获得的覆盖。这把程序等价与变异测试 \citep{budd1982,papadakis2019} 连接到生成 harness 群体的性能归因。

\paragraph{重复采样与集成。}
Pass@$k$ 衡量 $k$ 次采样中至少一次成功的概率；自一致性与相同智能体的集成则聚合多次尝试 \citep{chen2021codex,selfconsistency2022,moreagents2024}；名义温度为 $0$ 的调用也可能变化 \citep{nondeterminism2023}。本文将这些采样收益作为执行预算匹配时评估生成程序互补的显式参照。执行后的验证器对候选解排序 \citep{llmverifier2026}，集成选择则在验证集上选定模型组合，并在推理时平均其预测 \citep{caruana2004}。两者都评估或组合已生成的输出，而本文的选择器在程序执行前作出选择。本文的 oracle 重放与冻结选择器保留了这一差别。

\paragraph{选择与资源配置。}
HELIX 利用同一群体中不同 harness 的互补轨迹扩展经验证的覆盖，并为后续模型改进提供数据 \citep{helix2026}。STS 比较六种推理范式，训练基于嵌入的路由器，以实现部分 oracle 收益 \citep{sts2026}。本文固定目标模型，评估生成程序，并区分 oracle 覆盖、跨重复稳定的逐题优势与实际选择收益；同代码群体为这一区分提供采样参照。模型--问题组合间的 harness 敏感性 \citep{nouniversal2026}、所评估模型间的 harness 敏感性 \citep{nonmonotone2026}、搜索路由 \citep{cfrouting2026} 和基于偏好训练的模型路由 \citep{routellm2024}，将该问题连接到算法选择与组合求解 \citep{rice1976,xu2008satzilla,kotthoff2016}。GRASP 则在新增错误约束下选择对有界技能库的编辑 \citep{grasp2026}。定量交互与定性交互的区别 \citep{gailsimon1985} 解释了为什么效应大小变化未必改变最佳动作。本文的贡献是在同一程序群体中测量上述三种量，并揭示它们在何处出现分离。
