\subsection{面向 LLM 的 harness 生成}
\label{related:generation}
一条不断增长的研究线围绕冻结模型生成任务专属的脚手架。TTHE 用 LLM 提议/评判循环演化文本转 SQL harness \citep{tthe2026}；Self-Harness \citep{selfharness2026} 展示模型可以改进自己的 harness；JIT-Agent \citep{jitagent2026} 学会在推理时为每个任务生成 harness；Task-CoEvolve \citep{coevolve2026} 共同演化任务与脚手架。自动智能体程序搜索 \citep{adas2024} 最早把这类生成程序框定为搜索空间。2026 年的一个并行集群从验证侧让 harness 演化具备行为感知：HarnessLens \citep{harnesslens2026} 在演化过程中用行为级检查分配推演预算，HarnessFix \citep{harnessfix2026} 从有轨迹依据的诊断修复 harness，AHE \citep{ahe2026} 对照自声明的行为预测验证每次编辑，门控质量多样性／HarnessBank \citep{gatedqd2026} 在 LLM 标注的病理描述符上演化群体，Harness Handbook \citep{handbook2026} 针对行为定位与外环搜索，HarnessForge \citep{harnessforge2026} 共同演化 harness 与内部策略。

我们的分析单位与问题互补但不同。表~\ref{tab:nearest} 对比了两个最接近的系统。HarnessLens 把行为当作演化循环\emph{内部}的信号来分配算力；我们追问所得\emph{群体}作为一种结果属性是否行为多样。HarnessBank \citep{gatedqd2026} 记录搜索空间坍缩并按 LLM 给出的语义描述符筛除；我们的准入工具完全不给语义打分，而是驱动反事实轨迹探针，机械地验证一个声称的机制确实执行，并通过析因对比比较准入策略。由于所实现的门控也在结构上排除了两个被允许的提示转换，该处理不能在因果上分离验证本身。

\subsection{条件效用、路由与重复抽样}
\label{related:routing}
Harness 质量是依实例条件变化的：\citet{nouniversal2026} 与 \citet{nonmonotone2026} 记录了没有任何单一 harness 在所有实例上占优。HELIX 评估完整的兄弟 harness 结果矩阵以及超过最佳固定候选的群体互补性，但把路由器列为未来工作 \citep{helix2026}。STS 在六个固定的人工设计脚手架上路由 \citep{sts2026}，GRASP 把技能编辑门控进开发期库 \citep{grasp2026}，\citet{cfrouting2026} 学习在｛不搜索、搜索、弃权｝上路由，RouteLLM \citep{routellm2024} 在模型层面路由。底层决策边界是经典的定量与定性（交叉）交互之分：仅效应量改变并不一定改变应选的动作 \citep{gailsimon1985}。算法选择 \citep{rice1976} 与 SATzilla 这类组合求解器 \citep{xu2008satzilla,kotthoff2016} 根据实例特征在枚举的算法间选择，随机重启长期以来捕获的是对单个求解器多做尝试、而非来自组合的收益。集成选择在模型库上优化一个验证目标 \citep{caruana2004}，与执行前选择一个成员是不同的信息集；自一致 \citep{selfconsistency2022} 在事后聚合多条采样轨迹，其成本与信息集同样不同于执行前的单成员路由。

我们的候选是完整的、自动生成的 harness；我们测量一个选择器将继承的群体结果结构，而不是构建选择器。执行后验证器 \citep{llmverifier2026} 给已完成的轨迹打分，而我们的执行前估计目标在 harness 运行之前就做出选择，是不同的信息集；我们通篇把 oracle 覆盖明确标注为执行后、验证器可实现的上界，而非路由效用。

\subsection{生成群体中的行为多样性}
\label{related:diversity}
LLM 输出的多样性主要在样本层（pass@$k$ \citep{chen2021codex}、自一致、多样化解码）或智能体策略层被研究。对固定生成器重复抽样、以及由独立实例化的相同智能体组成多智能体集成 \citep{moreagents2024}，都已表明同代码额外执行能带来性能收益；名义温度 $0$ 的调用在重复间也会变化 \citep{nondeterminism2023}。我们的同代码克隆臂把这一执行层基线变成 harness 群体的显式被测量零假设。语法不同的程序行为相同，与经典的程序等价 \citep{budd1982} 和变异体等价 \citep{papadakis2019} 结果相邻。最接近的是 \citet{metaagents2025}，他们在聚合层面报告自动设计智能体行为多样性偏低；我们在两个方向上扩展该观察：一个轨迹层分类法（声称却未执行、存在却未触发、多轮损坏），确切说明语法差异在何处没有变成被执行的策略；以及反向发现——相同代码在重复执行下产生正的表观互补信号——并针对 harness 群体以匹配重复、同代码对照和显式的槽数/执行数/token 记账加以测量。
