\begin{abstract}
自动生成的 LLM harness 可以在源代码、实际执行的机制和正确性结果上有所不同，但这些差异未必意味着可重复的新增能力。我们在 BIRD 文本转 SQL 任务上研究这一问题。在发现阶段的一个种群中，尽管源代码不同，91 对 harness 中仍有 36 对在全部已评估题目上的正确性结果完全相同；轨迹检查发现了机制缺失、分支未触发和多轮路径失效。后续析因研究在六个构建器、三个种子上交叉设置策略强制与准入门控，使用 1,169 道题和官方 BIRD 评分器。自由生成已产生 8.6 个百分点的观测 oracle 提升空间。对存档实验的审后重分析估计，组合干预的效应为 $\RevisionPrimaryDelta$ 个百分点（95\% CI $\RevisionPrimaryCI$），未显示明确改善。实际门控还排除了两种原本允许的提示层策略，因此该对比无法单独识别验证的作用。重复执行显示结果不稳定，单次运行的 oracle 可以利用这种波动，而不要求稳定的机制互补。我们区分观测提升空间与稳定的题目—harness 优势，并说明将二者连接到实际选择收益所需的对照。当前证据明确了这些测量边界，尚未识别超出重复采样的稳定互补性。
\end{abstract}
