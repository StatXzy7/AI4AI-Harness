\begin{abstract}
自动生成的 LLM harness（脚手架）群体支撑着路由与价值预测，而这两类应用的前提是群体成员在\emph{结果}上彼此分歧。我们在 BIRD text-to-SQL 上审计了这一前提。Phase-I 发现性研究发现，一个标准 harness 演化群体在语法上多样、在行为上却已坍缩——91 对 harness 中有 36 对在每个任务上完全相同，代码相似度与结果分歧之间无关联——并通过执行轨迹审计把失败溯源到``机制有描述、从未执行''。一个手写的正控制表明路由所需的 headroom 是存在的（7.3\,pp）；失败出在生成侧。一项预先指定的确证性因子研究（策略强制 $\times$ 一致性门控；六构建器、三种子；来自从未打开过的数据库的 1{,}169 道题；官方 BIRD 评分器）随后两次改写了这一叙事。第一，坍缩被证明\emph{对协议敏感}：在干净且预算相等的协议下，自由的无门控生成本身就已产出 headroom 丰富的群体（8.6\,pp oracle headroom、31\% 联合修复率）。第二，干预\emph{没有明确改善}（$-0.16$\,pp，CI $[-0.90, +0.82]$）；表面上为负的门控效应在很大程度上受规模混淆（$K$ 匹配后为 $-0.30$\,pp，CI 跨越零），且 bare 结果的噪声底（温度 0 下 14.5\% 的翻转率）超过了所讨论的效应量。稳定的结论是一条测量准则：在生成群体之上做路由之前，先报告结果分歧、修复、伤害与 headroom——并且要审计生成协议本身，因为我们发现的坍缩对管线曾通过的所有代码级检查都不可见。
\end{abstract}

\subsection*{AI 使用声明}

本研究在构造上即是一个研究 AI 生成制品的 AI 辅助科研项目，我们在此精确披露辅助的程度。

\textbf{要求的披露。}我们使用生成式 AI 工具完成了：(i) 编写与修改实验代码（生成管线、评估采集器、统计分析脚本），这些代码通过自动化测试、与手写正控制及已知负突变体的校准比对、以及跨模型对抗性审查加以验证；(ii) 执行实验，包括本文报告的所有模型 API 调用；(iii) 分析实验数据并制作表格与图；以及 (iv) 起草与编辑稿件文本。本文中的每一个定量论断都由已提交、受版本控制的分析脚本从归档的原始输出中生成，且对预冻结协议的每一次偏离都在协议变更日志中披露。

\textbf{研究想法与方向。}核心研究问题、因果设计决策（估计量、对比、剔除规则）、解释标准以及全部 go/no-go 决策均由人类作者作出，AI 工具担任执行者以及一名对抗性审稿人（按我们的跨模型审查纪律，与执行者分属不同模型家族）。

\textbf{责任。}我们对本工作的最终内容负责，包括在生成式 AI 协助下产生的文本、论断与制品。本节中的事实陈述供作者核验；其准确性由作者承担最终责任。
