\begin{abstract}
生成的 LLM harness 究竟增加了任务特异能力，还是仅增加了获得正确答案的机会？本文在 MATH-500 的同一批 $\RcvPairedN$ 道完整观测分析题上，通过同代码对照区分覆盖、可重复性与可用选择。八个生成程序加一个基线，与九个逐字节相同的基线槽位比较，每个成员执行三次。尽管程序专长按构造为零，克隆仍产生 $\RcvClonePlugin$ 个百分点的重复平均 oracle 余量。生成程序的评分模式残差相关性远高于克隆（$\RcvRealRho$ 对 $\RcvCloneRho$），但持续输给基线的情况涉及 $\RcvLossTasks$ 道题，持续获胜却仅出现在一道题上。冻结特征选择器收益为零；执行 $27$ 次时，两臂 oracle 覆盖均为 $\RcvReplayFullCoverage\%$。留出重复证据尚未判清稳定互补性。补充的 BIRD 轨迹区分了缺失、未触发以及执行后破坏输出的机制。因此，在所测面板上，强可重复性既没有为冻结选择器带来收益，也没有使完整预算下的 oracle 覆盖超过同一程序的额外执行。
\end{abstract}

\subsection*{伦理声明}
全部实验使用公开的 BIRD 与 MATH-500 基准数据及生成的程序产物；不涉及人类被试、私人记录或个人身份信息。模型调用作为实验来源的一部分报告，论文不发布凭据或会暴露私人数据的提供方响应。主要伦理风险是夸大单次运行 oracle 增益对部署路由的含义；因此我们把未解决的选择与成本命题明确报告为 \textsc{Insufficient Evidence}（证据不足）。
