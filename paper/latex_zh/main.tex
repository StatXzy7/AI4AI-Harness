\begin{abstract}
推理预算应当用于更多程序，还是同一程序的更多次执行？本文通过区分答案覆盖、表现可重复性与可用选择，研究生成式 LLM harness 中的这一选择。在 MATH-500 的 $\RcvPairedN$ 道题上，我们将八个生成程序加一个基线，与九个逐字节相同的基线槽位比较，每个成员执行三次。相同程序已经产生 $\RcvClonePlugin$ 个百分点的重复平均 oracle 余量。生成程序的评分模式残差相关性更强（$\RcvRealRho$ 对 $\RcvCloneRho$），但这一结构主要由涉及 $\RcvLossTasks$ 道题的持续损失构成，持续获胜仅出现在一道题上。冻结选择器获得 $\RcvPolicyGain$ 个百分点的收益，两臂在 $27$ 次执行时均达到 $\RcvReplayFullCoverage\%$ 的 oracle 覆盖。留出重复尚未判清稳定互补性。补充的 BIRD 轨迹展示了实现、触发与输出有效性如何塑造执行行为。在所测面板上，可重复差异主要揭示程序在哪里失分，而额外执行基线能够达到相同的完整预算覆盖。
\end{abstract}
