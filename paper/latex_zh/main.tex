\begin{abstract}
当一个 LLM harness 群体比其中最好的成员覆盖更多任务时，收益来自程序专长，还是仅仅来自更多次尝试？本文区分执行后的覆盖、跨重复保持的任务优势，以及选择器实际获得的收益。关键对照是重复运行同一个程序：在 MATH-500 上，九个相同的单次调用槽虽然没有程序专长，重复平均后的 oracle 估计仍为正，达到 $\WpVthreeClonePlugin$\,\%；八个生成 harness 加基线在其自身完整任务集合上为 $\WpVthreePlugin$\,\%。通过留出重复并用克隆对照校准，在 $\WpVthreeNPaired$ 个配对任务上得到平均增益 $\WpVthreeD$\,\%；覆盖不完整和低灵敏度使稳定专长仍未判清。另一个独立冻结的选择器在每道题上都选择基线，收益为 $\WpPiZDiff$\,\%。这些结果揭示了一个归因问题：群体覆盖为正并不确立任务专长，而覆盖机会能否转化为可用选择，还需单独检验。本文提供了将这些判断分开的受控评估。所有增益均为以 \% 表示的绝对概率差。
\end{abstract}
