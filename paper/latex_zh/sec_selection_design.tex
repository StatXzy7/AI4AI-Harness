\paragraph{根据题目选择程序。}
我们在 $100$ 道开发题上，使用 TF-IDF 题目特征与训练折内的成员准确率训练 $\pi_Z$。五折任务级交叉验证将同题的重复保留在同一折。推断时平均五个折模型的概率向量，选择概率最高的成员；若前两名概率差小于 $0.15$，则回退到 \bare{}，并列按固定成员 ID 顺序处理。完整策略在评估前冻结。参照包括开发集选出的固定成员，以及随机抽取的一个固定成员。

\paragraph{向程序组合分配执行次数。}
离线 oracle 重放在预算 $b\in\{3,9,15,27\}$ 下，比较按开发集排名组成的程序组合与同代码执行。每个纳入成员贡献三次重复；克隆覆盖则精确平均其 $27$ 次记录执行中所有均匀大小为 $b$ 的子集。两臂均使用执行后的正确性衡量可用答案。补采集分析保持已记录的选择器决策与程序组合顺序不变。重放使用两臂均完整的题目，预算单位为 harness 执行，模型调用与 token 用量由程序决定。附录~\ref{app:selection} 给出策略、重放公式与记账细节。
