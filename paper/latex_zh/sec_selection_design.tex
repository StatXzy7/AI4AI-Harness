\paragraph{执行前的特征选择。}
重复诊断使用同一任务过去的结果，实际选择器则必须在看到答案前作出选择。我们在 $100$ 道开发题上训练 $\pi_Z$，使用 TF-IDF 题目特征与仅在训练折内计算的成员准确率，并采用任务级五折交叉验证：同题的重复始终留在同一折。策略在评估前冻结，当前两名概率差小于 $0.15$ 时回退至 \bare{}；它不能使用评估正确性或轨迹。比较对象包括开发集选出的固定成员与预先固定的随机成员。

\paragraph{执行后的 oracle 重放。}
另一次离线比较为按开发集表现排序的成员组合与克隆臂分配相同的执行次数 $b\in\{3,9,15,27\}$。每个入选成员贡献三次重复；克隆参照取其 $27$ 次记录执行的子集。两臂均在执行后使用正确性作 oracle 选择，衡量可获得的覆盖。一次 harness 执行可以包含多次模型调用，因此执行次数相等不等于调用数或 token 成本相等。附录~\ref{app:selection} 给出冻结策略、重放和账目细节，并与旧档案的选择分析明确区分。
