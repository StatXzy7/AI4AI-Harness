\paragraph{根据题目选择程序。}
我们使用 $100$ 题开发集拟合 $\pi_Z$，预测每题可用重复平均正确率最高的成员；训练标签并列时按成员 ID 顺序处理。五个任务折将同题重复保留在同一折。各拟合模型共享从开发题文本学习的 TF-IDF 词表，并将训练折内的成员准确率作为附加输入。推断时平均已拟合折模型的概率向量，选择概率最高的成员；前两名概率差小于 $0.15$ 时回退到 \bare{}，最高概率并列也因此触发回退。策略在评估前冻结，拟合与回退细节见附录~\ref{app:selection}。参照包括开发集选出的固定成员，以及随机抽取后固定的一个成员。

\paragraph{向程序组合分配执行次数。}
离线 oracle 重放在预算 $b\in\{3,9,15,27\}$ 下，比较按开发集排名组成的程序组合与同代码执行。每个纳入成员贡献三次重复；克隆覆盖是从其 $27$ 次记录执行中全部大小为 $b$ 的子集均匀抽取时的精确期望。两臂均使用执行后的正确性衡量可用答案。补采集分析保持已记录的选择器决策与程序组合顺序不变。重放使用两臂均完整的题目，预算单位为 harness 执行，模型调用与 token 用量由程序决定。附录~\ref{app:selection} 给出策略、重放公式与记账细节。
