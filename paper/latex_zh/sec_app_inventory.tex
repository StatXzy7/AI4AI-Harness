\subsection{模型与版本}\label{app:models}

表~\ref{tab:models} 列出所报告基准研究使用的模型及其发送给 API 的确切版本字符串。所有模型均通过单一商业 OpenAI 兼容 API 聚合器访问（每个角色都用同一提供方）。冻结的是目标模型身份；解码由各 harness 定义，single-call 基线的温度为 $0$。Phase-II harness 生成使用温度 0.7、16{,}384 token 预算；Phase-I 生成条件及其证据缺口见附录~\ref{app:phase1-provenance}。Phase I 使用代理执行评分器；Phase II 使用官方 BIRD 评分器（30\,s 超时），旧评分器作为次要审核。MATH-500 探查使用附录~\ref{app:crossdomain} 的答案比较器；报告的准确率无一由 LLM 评分器产生。
