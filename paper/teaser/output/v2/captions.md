## Academic option

**Coverage, repeatability, and usable selection separate.** Eight generated programs plus the single-call baseline are compared with nine byte-identical baseline slots on 386 common MATH-500 tasks, with three executions per slot. Identical code still produces positive repeat-averaged oracle headroom. Generated programs show stronger residual score-pattern correlation, but the frozen feature selector gains 0.00 percentage points over the development-selected fixed baseline. Error bars show 95% bootstrap intervals for the correlations. The clone-adjusted held-out-repeat gain leaves stable complementarity unresolved. Program glyphs are schematic.

## Illustrated option

**More programs do not improve full-budget oracle coverage in this panel.** The generated arm has eight selected programs plus the single-call baseline; the control has nine byte-identical baseline slots. Both are evaluated on 386 common MATH-500 tasks with three repeats per slot. Repeat-averaged oracle headroom is positive in both arms. At 27 harness executions per task, both arms attain 98.70% post-execution oracle coverage. Generated programs show more repeatable residual score patterns, yet the tested frozen selector gains 0.00 percentage points over the development-selected fixed baseline. Execution counts are matched; model-call and token costs vary. Held-out-repeat evidence leaves stable complementarity unresolved. The artwork is conceptual.

Abbreviations: pp, percentage points; r, residual score-pattern correlation; CI, confidence interval. Detailed definitions and the illustrated option's correlation intervals are in `design_notes.md`.
