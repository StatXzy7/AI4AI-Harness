\textbf{Open-set value prediction does not beat the best fixed harness.} A
leave-one-harness-out predictor over the Phase-I admitted populations fails to beat
the best fixed harness (DeepSeek arm $-3.4$\,pp, Qwen $+0.9$\,pp, CI
$[-5.2, +6.9]$; cross-protocol pool $-0.9$\,pp). Apparent per-fold repair AUROC of
0.82--0.98 collapses under database-stratified task-held-out controls (mean 0.512)
--- within this tested configuration the signal is task memorization, not
harness-value estimation. One narrow positive survives: on the 24-harness
cross-protocol pool, the same predictor as an \emph{abstaining gate} gained
$+6.9$\,pp over bare with zero \emph{observed} induced harm --- measured on the
same tasks the gate was tuned on, so it is not a deployment claim. Selective
abstention may be easier than full routing; the open problem --- estimating an
unseen harness's per-item value from code and task text alone --- remains open.
