## Statistical audit (any remaining false-support path, with a concrete counterexample you constructed or ran if you can)

The complete-data simulations provide some empirical reassurance but do not establish the advertised size guarantee. Across the supplied complete-data null grid, the maximum observed v3 false-support rate is 4.67% (`equal_const`, `M=9,T=100,R=3`; Wilson interval 2.28–9.32%).

I independently ran an additional dominance-cone stress test with one member weakly dominating every task, `M=20,T=30,R=3`, heterogeneous subdominant gaps, 300 datasets per gap. False support occurred in:

- 2/300 at zero boundary gap;
- 1/300 at gap .002;
- 5/300 at gap .01;
- 5/300 at gap .03.

These rates are not evidence of inflation by themselves, but they concretely refute the prose claim that dominance “can never” false-support. A level-.05 procedure can false-support under \(H=0\); the defensible claim is controlled probability, not impossibility.

The calibration suite has a more serious defect: **every v3 missingness cell has `error_rate=1.0`**, `abstain_rate=0`, and no estimate. The seed calculation calls `int(Y.sum())` after NaNs are introduced. Those errors are then displayed as zero support. Therefore the paper’s statements that MCAR/MNAR calibration passed and missingness did not affect FPR are false.

The calibration fast path also differs from production:

- it applies a bootstrap interval to \(D\) but uses it as `g_lo`;
- it checks only `g_obs > 0`, not the production \(G_{\rm real}\) lower-bound rule;
- it hard-codes `n=342`;
- it uses one tie draw, while the manuscript claims ten for real data.

Consequently Table 5 does not calibrate the actual production decision rule.

## Fill And Validate AcroForms

Visual review alone is not a correctness check for a fillable PDF. A page `/Widget` annotation can render a value from its appearance stream while the canonical `/AcroForm/Fields` tree is missing or contains a stale value.

1. Keep the result interactive by default; set `flatten=True` only when the user explicitly requests a completed, static form. Preserve the source PDF, and do not flatten a signed PDF without an explicit workflow decision.
2. Inspect both representations before filling: enumerate fields from `reader.get_fields()` and `/Widget` annotations from every page's `/Annots`, following `/Parent` and `/Kids`. If a widget and a canonical field have the same name but are distinct objects with no `/Parent` relationship, do not call `reattach_fields()` blindly: it can create a second top-level field with the same name. Report the ambiguity or produce a static result.
3. Recover genuinely orphaned widgets, fill all pages, and write the result with `pypdf`:

```python
from pypdf import PdfReader, PdfWriter
from pypdf.generic import NameObject

reader = PdfReader(input_pdf)
writer = PdfWriter()
writer.clone_document_from_reader(reader)

# Restores widgets that are missing from /AcroForm/Fields.
writer.reattach_fields()
fields = writer.get_fields() or {}
missing = set(expected_values) - set(fields)
if missing:
    raise ValueError(f"Form fields not found after repair: {sorted(missing)}")

values_to_write = dict(expected_values)
if flatten:
    # Paint every existing value before removing every widget.
    values_to_write = {
        name: field.get("/V", "/Off" if field.get("/FT") == "/Btn" else "")
        for name, field in fields.items()
    }
    values_to_write.update(expected_values)

writer.update_page_form_field_values(
    None, values_to_write, auto_regenerate=False, flatten=flatten
)

if flatten:
    # pypdf's flatten=True paints appearances but does not remove widgets.
    writer.remove_annotations(subtypes="/Widget")
    writer.root_object.pop(NameObject("/AcroForm"), None)

with open(output_pdf, "wb") as stream:
    writer.write(stream)
```

  91:     high accuracy), the argmax adds iid $U(0,10^{-9})$ jitter from
  92:     `tie_rng`, so every tied label has equal probability. A deterministic
  93:     lexicographic tie-break gives the first listed member a systematic
  94:     selection advantage and makes G depend on member ordering (an
  95:     adversarial finding from the design review); symmetric jitter removes
  96:     that bias. The jitter is orders of magnitude below any non-tie score
  97:     gap and therefore never changes a non-tied ordering.
  98:     """
  99:     R, M, T = Y.shape
 100:     if cols is None:
 101:         cols = _complete_cols(Y)
 102:     per_task = np.zeros(len(cols))
 103:     folds = []
 104:     for v in range(R):
 105:         K = [r for r in range(R) if r != v]
 106:         qd = np.mean([Y[r][:, cols] for r in K], axis=0)
 107:         # tie_rng=None -> lexicographic (deterministic) selection, used only
 108:         # for exact vectorization comparisons; all scientific paths pass a
 109:         # seeded rng and get label-symmetric tie-breaking.
 110:         if tie_rng is not None:
 111:             qd = qd + tie_rng.random(qd.shape) * 1e-9
 112:         h_star = np.argmax(qd, axis=0)
 113:         fs = qd.mean(axis=1)
 114:         if tie_rng is not None:
 115:             fs = fs + tie_rng.random(fs.shape) * 1e-9
 116:         h_fix = int(np.argmax(fs))
 117:         yv = Y[v][:, cols]
 118:         per_task += (yv[h_star, np.arange(len(cols))]
 119:                      - yv[h_fix, np.arange(len(cols))]) / R
 120:         folds.append({"held_out_repeat": v, "best_fixed": h_fix,
 121:                       "n_distinct_selection": int(len(set(h_star.tolist())))})
 122:     if return_folds:
 123:         return float(per_task.mean()), per_task, folds
 124:     return float(per_task.mean()), per_task, folds

 140: def _batch_permuted(Y: np.ndarray, cols: np.ndarray, n_perm: int,
 141:                     rng: np.random.Generator) -> np.ndarray:
 142:     """Batched member-label randomization of Y[:, :, cols].
 143: 
 144:     Returns (B, R, M, t): independent uniform member-label permutations per
 145:     (permute draw, repeat, task), applied to the corresponding held rows.
 146:     Independent permutations across repeats break discovery-to-validation
 147:     identity transfer while preserving margins.
 148:     """
 149:     R, M, _ = Y.shape
 150:     t = len(cols)
 151:     Yc = Y[:, :, cols]                                  # (R, M, t)
 152:     keys = rng.random((n_perm, R, t, M))
 153:     perms = np.argsort(keys, axis=3)                    # (B, R, t, M)
 154:     idx = np.broadcast_to(perms, (n_perm, R, t, M))
 155:     Yb = np.broadcast_to(Yc[None, :, :, :], (n_perm, R, M, t))
 156:     # gather row perm[..., m] for each output row m
 157:     return np.take_along_axis(
 158:         Yb.swapaxes(2, 3), np.broadcast_to(perms, (n_perm, R, t, M)), axis=3
 159:     ).swapaxes(2, 3).copy()

 162: def _batch_crossfit_gain(Yb: np.ndarray, jitter: bool = True) -> np.ndarray:
 163:     """Vectorized crossfit_gain over a batch (B, R, M, t) of tensors.
 164: 
 165:     With jitter=True, symmetric iid U(0,1e-9) tie-breaking is added per
 166:     (draw, fold, task) and (draw, fold, fixed choice); this is the batched
 167:     counterpart of the seeded tie_rng used by the single-tensor path."""
 168:     B, R, M, t = Yb.shape
 169:     out = np.zeros((B, t))
 170:     rng = np.random.default_rng(12345)
 171:     for v in range(R):
 172:         K = [r for r in range(R) if r != v]
 173:         qd = Yb[:, K, :, :].mean(axis=1)                # (B, M, t)
 174:         if jitter:
 175:             qd = qd + rng.random(qd.shape) * 1e-9
 176:         h_star = np.argmax(qd, axis=1)                  # (B, t)
 177:         fscores = qd.mean(axis=2)
 178:         if jitter:
 179:             fscores = fscores + rng.random((B, M)) * 1e-9
 180:         h_fix = np.argmax(fscores, axis=1)              # (B,)
 181:         held = Yb[:, v, :, :]                           # (B, M, t)
 182:         bidx = np.arange(B)[:, None]
 183:         tidx = np.arange(t)[None, :]
 184:         picked = held[bidx, h_star, tidx]               # (B, t)
 185:         fixed = held[bidx, h_fix[:, None], tidx]        # (B, t)
 186:         out += (picked - fixed) / R
 187:     return out.mean(axis=1)

 190: def randomization_D_pvalue(Y: np.ndarray, clone_Y: np.ndarray,
 191:                            cols: np.ndarray, c_cols: np.ndarray,
 192:                            d_obs: float, n_perm: int,
 193:                            rng: np.random.Generator,
 194:                            delta: float = DELTA
 195:                            ) -> tuple[float, float, np.ndarray]:
 196:     """Vectorized two-arm randomization p-value for D = G_real - G_clone.
 197: 
 198:     Member labels are permuted independently per (repeat, task) in each arm
 199:     on every draw. Returns (one-sided p for gain, equivalence p, null D)."""
 200:     Rp = _batch_crossfit_gain(_batch_permuted(Y, cols, n_perm, rng))
 201:     Cp = _batch_crossfit_gain(_batch_permuted(clone_Y, c_cols, n_perm, rng))
 202:     null_D = Rp - Cp
 203:     p_gain = (1 + int(np.sum(null_D >= d_obs - delta))) / (n_perm + 1)
 204:     p_equiv = (1 + int(np.sum(null_D >= d_obs + delta))) / (n_perm + 1)
 205:     return float(p_gain), float(p_equiv), null_D

# Response to the 2026-09-19 external review (3/10)

All substantive issues are addressed in a new revision; every statistical
change is validated offline (no new paid model calls). Below we answer the

## Q1. Which output is the calibrated "C-comp"? Explain the clone arm result.

The scientific C-comp state is now
`E1_C-rank_E2_C-comp.stable_complementarity.clone_calibrated` produced by
`experiment/diagnostics/ccomp_v3.py`. The old repeat-averaged block is
renamed `descriptive_plugin` and can never determine a state.

Rules separating descriptive from scientific output:

1. The plug-in max of noisy per-task estimates is always printed under
   `descriptive_plugin.H_hat` with an explicit upward-bias warning.
2. The scientific estimand is the cross-fitted frozen-selection gain
   `G`: in each of three folds, two repeats freeze BOTH the per-task
   member mapping h*(x) AND the single best fixed member h_fix; the held-
   out repeat scores the frozen mapping against that fixed member
   (never bare).
3. The decision statistic is `D = G_real − G_clone`, with an exact
   two-arm randomization p-value (member labels permuted independently
   within each task AND repeat in both arms) and a paired task bootstrap.
4. A SUPPORTED state requires the coverage gate, randomization p < .05,
   bootstrap lower bound > 0, D > 1pp, and a positive G_real lower bound.

On the sealed data: descriptive plug-in = 2.54pp real / 2.67pp clone
(known biased; the clone value is the reviewer's exact point made
empirically); G_real = 0.17pp [−0.82, 1.31]; G_clone = 0.55pp;
D = −0.10pp [−1.55, 1.46], p = .77; state INSUFFICIENT_EVIDENCE
(coverage gate 12.5% > 10%). The tie-break is label-symmetric iid
jitter averaged over 10 frozen draws in BOTH arms (production); the
calibration fast path is the same decision rule with n_tie=1, the
same two confidence guards, the same paired-task alignment and
coverage gate (verified identical logic, not a parallel
implementation).

## Q2. A8.6 output under the bare=0.5 / others=0.9 example.

That statistic cannot distinguish global dominance from complementarity:
its expectation is ≈ 0.5·(1−0.1^8)·0.4 ≈ 0.20. We encode the example as a
regression test (`test_w2_global_dominance_no_support`) and relabel A8.6
(`E2_legacy_vs_bare_A86`, field `estimand_status`) as a SECONDARY /
DESCRIPTIVE post-discovery advantage over bare, never a C-comp test.

The primary v3 estimand compares the frozen selector with the best FIXED
member. Under the 0.5/0.9 configuration the frozen best-fixed member is
one of the 0.9 members on discovery folds and G_real ≤ 0 in population;
the randomization test does not support (verified FPR = 0 over repeated
draws). The two-arm subtraction makes this exact at equal ability and
conservative throughout the dominance null family.

## Q3. "Equal budget" — precise definition and the spend discrepancy.

Three comparisons are now explicitly separated in §6.2 and
Appendix C:

- Equal-slot collection (what was run): 9 members/slots × 3 repeats each.
- Common per-task execution budget (cost-controlled): offline
  `wp1r_budget.py` compares the dev-ranked panel with b ∈ {3,6,…,27}
  of the 27 same-code executions under POST-EXECUTION ORACLE coverage
  (official judge per execution); coverage is tied (−0.25 to +0.37pp).
- Cross-arm majority-vote accuracy is NOT reported: the arms emit
  incompatible answer formats (harnesses box a number; bare emits
  free-form prose), so no modal-answer key is fair across styles.

  28: \begin{abstract}
  29: Automatically generated LLM harnesses offer a rich design space, but their
  30: source-code, execution, and outcome diversity must be measured separately.
  31: We define five separately reported claim classes --- measurement
  32: sufficiency, single-shot coverage, \emph{stable ranking},
  33: \emph{stable complementarity}, pre-execution selectability, and
  34: budget-matched utility --- and give the two stability claims
  35: size-controlled tests. The complementarity test freezes a per-task member
  36: mapping on discovery repeats, scores it on held-out repeats against the
  37: best \emph{fixed} member (global dominance can then never look like
  38: complementarity), and calibrates against a same-code clone arm with a
  39: Monte Carlo randomization test. Known-truth simulations establish its
  40: false-support rate and power across member, task, and repeat counts:
  41: the prior repeat-averaged estimator false-supports on pure execution
  42: noise in every null regime we test, whereas the calibrated test keeps the
  43: false-support rate at its nominal level and detects interaction only when
  44: repeats suffice for a reliable mapping. Applied to a fresh pre-registered
  45: MATH-500 collection (eight generated harnesses and nine byte-identical
  46: \bare{} clone slots, three independent repeats each), the panel shows a
  47: stable member ranking, yet the clone-calibrated selection gain is
  48: $\WpVthreeD$\,pp (95\% CI $\WpVthreeDCI$; randomization $p=\WpVthreeP$):
  49: the evidence neither establishes a gain beyond independent executions of
  50: one fixed program at the declared $1$\,pp margin nor equivalence, and a
  51: frozen coverage gate keeps the verdict at \textsc{Insufficient
  52: Evidence}. On BIRD text-to-SQL, trace inspection and a versioned

   1: The boundary results above are statements about what single-run numbers
   2: cannot establish. We package an offline diagnostic on an execution matrix
   3: $Y[h,x,r,c]$ (member, task, repeat, condition) returning one of four
   4: states per class --- SUPPORTED, REFUTED\_WITHIN\_SCOPE,
   5: INSUFFICIENT\_EVIDENCE, NOT\_APPLICABLE --- with scope and minimal
   6: missing evidence, never collapsed into a score: \textbf{(A)} measurement
   7: sufficiency; \textbf{(B)} single-shot coverage; \textbf{(C)} stability
   8: in two estimands; \textbf{(D)} pre-execution selectability (frozen
   9: $\pi_Z$ vs dev-fixed); \textbf{(E)} budget-matched policy utility
  10: ($\lambda{=}1$, gated on verified call evidence).
  11: 
  12: \textbf{Two stability claims.} \emph{C-rank} asks whether some member
  13: pair differs under a simultaneous interval (max-T over all canonical
  14: pairs, family-wise 95\%) with sign-consistent repeats; pair direction is
  15: fixed by member identity, not list position. \emph{C-comp} asks whether
  16: stable task--harness interaction exists. With
  17: $\Delta(x)=p_1(x)-p_0(x)$ and $(u)_+=\max(u,0)$,
  18: \begin{equation}
  19: H_{\rm stable}=\mathbb{E}\,\Delta(x)_+-(\mathbb{E}\Delta(x))_+
  20: =\tfrac12\bigl(\mathbb{E}|\Delta(x)|-|\mathbb{E}\Delta(x)|\bigr),
  21: \label{eq:identity}
  22: \end{equation}
  23: so a member better \emph{everywhere} gives a stable ranking difference
  24: with $H_{\rm stable}{=}0$: global dominance refutes complementarity.
  25: Interaction requires the advantage to \emph{cross} tasks, and any
  26: pre-execution selection gap is bounded by $H_{\rm stable}$. Identity
  27: gates require equal condition fields, constant source hashes, and ---
  28: when matrices coincide --- distinct independent-execution provenance.
  29: 
  30: \textbf{Why the plug-in cannot decide, and the calibrated test.}
  31: Plugging $R$-repeat averages into $H_{\rm stable}$ maximizes noisy
  32: per-task estimates; resampling tasks cannot remove that selection noise
  33: (Table~\ref{tab:calibration}: the plug-in false-supports at rate
  34: $\approx1$ on every null at $M{=}9,T{=}400,R{=}3$, including $q\equiv0.9$
  35: and the sealed clone arm at $\WpVthreeClonePlugin$\,pp). We cross-fit a
  36: \emph{frozen-selection gain}: fold $v$ freezes on the other repeats both
  37: the per-task mapping $h_v(x)=\arg\max_h\bar q_h(x)$ and the best fixed
  38: member $\bar h_v=\arg\max_h\mathbb E_x\bar q_h(x)$, then scores
  39: $g_v(x)=Y_{h_v(x),x,v}-Y_{\bar h_v,x,v}$ on the held-out repeat,
  40: $G=\mathbb E_{x,v}g_v(x)$.\label{sec:calibration-test}
  41: Under dominance the frozen mapping is the best fixed member ($G\le0$),
  42: and $0\le G\le H_{\rm stable}$. The decision statistic is
  43: $D=G_{\rm real}-G_{\rm clone}$ on identical tasks, with a two-arm
  44: Monte Carlo randomization test ($+1$; labels permuted independently
  45: per task and repeat in both arms) and a paired task bootstrap. The
  46: reference is exact at equal ability; over the rest of the dominance
  47: cone finite-sample false-support is verified empirically in the grid
  48: below, not asserted analytically. Without a clone arm $G$ is
  49: descriptive and no SUPPORTED is emitted; a $\le10\%$ incomplete-task
  50: coverage gate and extremal unknown-cell bounds complete the rule.
  51:

"""Known-truth simulation DGPs for statistical calibration of the
stable-complementarity diagnostics.

Every DGP returns a binary outcome tensor Y with shape (R, M, T) drawn
from a fully specified member x task probability matrix Q[M, T], plus a
ground-truth record:

  H_stable = mean_t max_m Q[m,t] - max_m mean_t Q[m,t]
  null_family in {"equal_ability", "dominance", "crossover"}
  notes     human-readable generating mechanism

A *clone-arm* draw for the same tasks uses the SAME task difficulties but
sets every slot's probability to the bare/reference profile (optionally
including slot-level fixed effects to stress exchangeability).

The DGPs deliberately cover every null and alternative the 2026-09-19
external review asked the calibration to distinguish:
  D1 equal-ability iid noise       (all q identical; H = 0)
  D2 task-difficulty heterogeneity (common a_t, members tied; H = 0)
  D3 global dominance              (one member best everywhere; H = 0)
  D3b global dominance vs weak bare (0.5/0.9 reviewer counterexample 2)
  D4 genuine crossover interaction (specialization across task types; H > 0)
  D5 correlated executions          (shared latent execution quality)
Missingness is applied separately by apply_missingness (MCAR or
difficulty-related MNAR) so each mechanism is reusable under both.

Everything here is offline, numpy-only, and deterministic given a seed.
"""
from __future__ import annotations

from dataclasses import dataclass

import numpy as np


@dataclass(frozen=True)
class DGPResult:
    Y: np.ndarray                 # (R, M, T) Bernoulli draws
    Q: np.ndarray                 # (M, T) generating probabilities
    H_true: float                 # target parameter on the generating Q
    null_family: str
    task_types: np.ndarray        # (T,) integer latent type labels
    description: str


def _sigmoid(z: np.ndarray) -> np.ndarray:
    return 1.0 / (1.0 + np.exp(-np.clip(z, -40, 40)))


def _task_difficulties(rng: np.random.Generator, T: int,
                       lo: float = 0.55, hi: float = 0.99,
                       k_types: int = 1) -> tuple[np.ndarray, np.ndarray]:
    """Beta-ish task difficulties via sigmoid of a normal, spread over [lo,hi]."""
    z = rng.normal(0.0, 1.0, size=T)
    a = lo + (hi - lo) * _sigmoid(1.4 * z)
    types = rng.integers(0, k_types, size=T) if k_types > 1 else np.zeros(T, int)
    return a, types


def _draw(Q: np.ndarray, R: int, rng: np.random.Generator,
          exec_rho: float = 0.0) -> np.ndarray:
    """Draw R repeats. exec_rho>0 induces within-repeat shared latent
    execution quality (e.g. server-side sampling correlation): a repeat-
    level normal shift applied jointly to all members on each task."""
    M, T = Q.shape
    if exec_rho <= 0.0:
        return (rng.random((R, M, T)) < Q[None, :, :]).astype(float)
    # Gaussian latent copula-style correlation: per (repeat, task) shared
    # shift u, per-cell noise e, corr(u_shock, total_shock) tuned loosely.
    Y = np.empty((R, M, T))
    for r in range(R):
        u = rng.normal(0.0, exec_rho, size=(1, T))
        e = rng.normal(0.0, 1.0, size=(M, T))
        z = np.log(np.clip(Q, 1e-6, 1 - 1e-6) /
                   (1 - np.clip(Q, 1e-6, 1 - 1e-6)))
        p = _sigmoid(z + u + 0.0)  # shared shift moves all members together
        Y[r] = (rng.random((M, T)) < p).astype(float)
    return Y

def dgp_equal_ability(seed: int, M: int = 9, T: int = 400, R: int = 3,

                         across members), so the bootstrap must not mistake
                         difficulty variance for member-task interaction.
    H_stable = 0 by construction.
    """
    rng = np.random.default_rng(seed)
    if heterogeneity:
        a, types = _task_difficulties(rng, T)
    else:
        a, types = np.full(T, q), np.zeros(T, int)
    Q = np.tile(a[None, :], (M, 1))
    Y = _draw(Q, R, rng, exec_rho)
    return DGPResult(Y=Y, Q=Q, H_true=0.0, null_family="equal_ability",
                     task_types=types,
                     description=("iid equal-ability q=%.2f" % q
                                  if not heterogeneity else
                                  "equal-ability with shared task difficulty"))

def dgp_global_dominance(seed: int, M: int = 9, T: int = 400, R: int = 3,
                         gap: float = 0.4, base_q: float = 0.5,
                         heterogeneous: bool = True,
                         member_spread: bool = True,
                         dominant_index: int = 1,
                         exec_rho: float = 0.0) -> DGPResult:
    """One fixed member is expectation-best on EVERY task (H_stable = 0),
    while other members may be much better/worse than the reference.

    Defaults instantiate reviewer counterexample 2: the reference member
    (index 0) has q=0.5 on all tasks, the other 8 members q=0.9, so any
    vs-bare discovery statistic shows a large gain despite zero
    complementarity. dominant_index moves the dominant profile to another
    slot (index 0 = the clean zero-G null where tie-breaking favors the
    dominant member).

    heterogeneous: add shared task-difficulty variation around the levels.
    member_spread: give non-dominant members small fixed offsets, all still
                   strictly below the dominant member.
    """
    rng = np.random.default_rng(seed)
    a, types = _task_difficulties(rng, T) if heterogeneous else \
        (np.full(T, 0.775), np.zeros(T, int))
    # center the difficulty swing so mean(base)=base_q and mean(dom)=base_q+gap
    a = a - a.mean()
    Q = np.empty((M, T))
    weak_levels = np.full(M, base_q)
    for m in range(M):
        offset = 0.0 if not member_spread else (m - M / 2) * 0.01
        weak_levels[m] = base_q + offset
    for m in range(M):
        Q[m] = np.clip(weak_levels[m] + a, 0.02, 0.98)
    Q[dominant_index] = np.clip(base_q + gap + a, 0.02, 0.99)
    # guarantee strict dominance of the dominant member
    for m in range(M):
        if m != dominant_index:
            Q[m] = np.minimum(Q[m], Q[dominant_index] - 0.02)
    Y = _draw(Q, R, rng, exec_rho)
    H = float(Q.max(axis=0).mean() - Q.mean(axis=1).max())
    return DGPResult(Y=Y, Q=Q, H_true=H, null_family="dominance",
                     task_types=types,
                     description=("global dominance: member %d=%.2f vs base=%.2f"
                                  % (dominant_index, base_q + gap, base_q)))

def dgp_crossover(seed: int, M: int = 9, T: int = 400, R: int = 3,
                  gamma: float = 0.12, base_q: float = 0.88,
                  k_types: int = 3, specialization: float = 1.0,
                  noise_members: int = 0,
                  exec_rho: float = 0.0) -> DGPResult:
    """Genuine task x member interaction: each member is specialized for one
    latent task type, so the per-task argmax crosses members across tasks
    and H_stable > 0.

    Q[m,t] = sigmoid(logit(base + a_t) + gamma * s[m,type(t)])
    Specialization profiles sum to zero within a type, and each type has a
    distinct best member. `noise_members` members get a flat (non-specialized)
    profile near base_q to mimic panel members that carry no interaction.
    """
    rng = np.random.default_rng(seed)
    a, types = _task_difficulties(rng, T, lo=0.6, hi=0.98, k_types=k_types)
    a = a - a.mean()
    # specialization score matrix S[M, k_types]: cyclic assignment, each
    # type has a distinct winner; rows for noise members are flat zero.
    S = np.zeros((M, k_types))
    n_active = M - noise_members
    for m in range(n_active):
        for k in range(k_types):
            # triangular wave: member m peaks at type m mod k_types
            d = abs(((m - k) % max(1, n_active)))
            S[m, k] = specialization * (1.0 if d == 0 else -0.6 / max(1, d))
    z = np.log(np.clip(base_q + a[:, None], 1e-6, 1 - 1e-6) /
               (1 - np.clip(base_q + a[:, None], 1e-6, 1 - 1e-6)))
    Q = _sigmoid(z.T + gamma * S[:, types]).clip(0.02, 0.99)
    Y = _draw(Q, R, rng, exec_rho)
    H = float(Q.max(axis=0).mean() - Q.mean(axis=1).max())
    return DGPResult(Y=Y, Q=Q, H_true=H, null_family="crossover",
                     task_types=types,
                     description=f"crossover gamma={gamma}, k={k_types}, "
                                 f"H={H:.3f}")


def dgp_two_specialist(seed: int, M: int = 9, T: int = 400, R: int = 3,
                       base_q: float = 0.6, gap: float = 0.35
                       ) -> "DGPResult":
    """CLEAN two-specialist crossover power DGP.

    Two members are strong specialists on two disjoint task halves
    (base+gap); the remaining M-2 members are at base everywhere.
    H_stable = gap/2 and the frozen selector can recover it once discovery
    repeats separate a specialist from the base crowd --- unlike the cyclic
    multi-specialist dgp_crossover, where same-type specialists compete and
    dilute the selectable gain. This is the positive-control power curve."""
    rng = np.random.default_rng(seed)
    _, types = _task_difficulties(rng, T, k_types=2)
    Q = np.full((M, T), base_q)
    Q[0, :T // 2] = min(0.99, base_q + gap)
    Q[1, T // 2:] = min(0.99, base_q + gap)
    H = float(Q.max(0).mean() - Q.mean(1).max())
    Y = _draw(Q, R, rng)
    return DGPResult(Y=Y, Q=Q, H_true=H, null_family="crossover",
                     task_types=np.array(types),
                     description=f"two strong specialists +/- {gap} over base {base_q}")


def dgp_partial_crossover(seed: int, M: int = 9, T: int = 400, R: int = 3,
                          frac_cross: float = 0.25, gap: float = 0.10,
                          base_q: float = 0.9) -> DGPResult:
    """Small-H alternative: a globally best member except on a fraction of
    tasks where another member wins. Used to map power near the 1 pp margin."""
    rng = np.random.default_rng(seed)
    a, _ = _task_difficulties(rng, T)
    a = a - a.mean()
    Q = np.broadcast_to(base_q + a, (M, T)).copy()
    cross_idx = rng.choice(T, size=int(frac_cross * T), replace=False)
    Q[0, cross_idx] = np.clip(base_q + a[cross_idx] - gap, 0.02, 0.99)
    Q[1, cross_idx] = np.clip(base_q + a[cross_idx] + gap, 0.02, 0.99)
    # member 1 best elsewhere
    Q[1, :] = np.maximum(Q[1, :], Q[0, :] + 0.02)
    Q[1, cross_idx] = Q[0, cross_idx] - 0.04
    Y = _draw(Q, R, rng)
    H = float(Q.max(axis=0).mean() - Q.mean(axis=1).max())
    return DGPResult(Y=Y, Q=Q, H_true=H, null_family="crossover",
                     task_types=np.isin(np.arange(T), cross_idx).astype(int),
                     description=f"partial crossover frac={frac_cross}, H={H:.3f}")


# ------------------------------------------------------------- clone-arm draw

def draw_clone_arm(Q_real: np.ndarray, task_types: np.ndarray, R: int,
                   seed: int, base_member: int = 0,
                   slot_effect_sd: float = 0.0,
                   exec_rho: float = 0.0) -> np.ndarray:
    """Same-code clone slots for the same tasks.

    All slots share the reference member's probability profile. Nonzero
    slot_effect_sd adds fixed slot-level offsets (a stress test of the
    exchangeability assumption; default 0 = exact same code)."""
    rng = np.random.default_rng(seed)
    M = Q_real.shape[0]
    base = Q_real[base_member]
    Qc = np.tile(base[None, :], (M, 1))
    if slot_effect_sd > 0:
        offsets = rng.normal(0.0, slot_effect_sd, size=(M, 1))
        Qc = np.clip(Qc + offsets, 0.02, 0.99)
    return _draw(Qc, R, rng, exec_rho)


# -------------------------------------------------------------- missingness

def apply_missingness(Y: np.ndarray, seed: int, frac: float,
                      mechanism: str = "mcar",
                      Q: np.ndarray | None = None) -> np.ndarray:
    """Return a copy of Y with NaN cells.

    mechanism='mcar': cells removed uniformly at random.
    mechanism='mnar_hard': removal probability is higher for hard tasks
        (low Q) and concentrated on specified members, mimicking provider
        timeouts on long/hard items; informative, never ignorable.
    """
    rng = np.random.default_rng(seed)
    out = Y.copy()
    R, M, T = out.shape
    if mechanism == "mcar":
        mask = rng.random((R, M, T)) < frac
        out[mask] = np.nan
    elif mechanism == "mnar_hard":
        if Q is None:
            raise ValueError("mnar_hard requires Q")
        # harder tasks (low max Q) are more likely to be missing, plus a
        # member-specific vulnerability
        hard = 1.0 - Q.max(axis=0)
        p = np.clip(3.0 * frac * (0.3 + hard / max(hard.max(), 1e-9)), 0, 0.9)
        for m in range(M):
            pm = p * (2.0 if m >= M - 2 else 0.6)
            u = rng.random((R, T))
            out[:, m, :][u < pm[None, :]] = np.nan
    else:
        raise ValueError(f"unknown missingness mechanism {mechanism}")
    return out

"""Render the known-truth calibration results into a compact LaTeX table.

Reads artifacts/diagnostics/calibration_v3/calibration_results.json and
writes paper/latex/calibration_table.tex: one row per (scenario, design
cell) showing the false-support (nulls) / power (alternatives) rates of
the legacy plug-in versus the clone-calibrated v3 decision at the actual
acquisition design, plus the R-sweep rows.
"""
from __future__ import annotations

import json
from pathlib import Path

ROOT = Path(__file__).resolve().parents[2]
SRC = ROOT / "artifacts/diagnostics/calibration_v3/calibration_results.json"
OUT = ROOT / "paper/latex/calibration_table.tex"

# scenarios shown in the paper, grouped; columns: plugin FPR/power, v3
# FPR/power at the (9,400,R) design and the R sweep
ORDER = [
    ("equal_const", "equal ability $q{=}0.9$ (const.)", "null"),
    ("equal_hetero", "equal ability + task difficulty", "null"),
    ("dominance_clean", "dominance, dominant $=$ best fixed", "null"),
    ("dominance_reviewer", "dominance: others $0.9$ vs bare $0.5$", "null"),
    ("dominance_hetero", "dominance + heterogeneous tasks", "null"),
    ("cross_mid", "crossover (cyclic), $H\\approx0.9$\\,pp", "alt"),
    ("cross_strong", "crossover (cyclic), $H\\approx1.8$\\,pp", "alt"),
    ("cross_vstrong", "crossover (cyclic), $H\\approx4.2$\\,pp", "alt"),
    ("two_specialist", "two strong specialists, $H{\\approx}17.5$\\,pp", "alt"),
]


def cell(results, scenario, M=9, T=400, R=3, missing="complete"):
    for r in results:
        if (r["scenario"] == scenario and r["M"] == M and r["T"] == T
                and r["R"] == R and r["missing"] == missing):
            return r
    return None


def pct(x):
    return "---" if x is None else f"{100 * x:.0f}"


def main() -> None:
    data = json.loads(SRC.read_text(encoding="utf-8"))
    results = data["results"]
    short = {
        "equal_const": r"equal $q{=}0.9$$^\dagger$",
        "equal_hetero": r"equal + difficulty$^\dagger$",
        "dominance_clean": None,
        "dominance_reviewer": r"$0.5/0.9$ dominance$^\dagger$",
        "dominance_hetero": r"dominance$^\dagger$",
        "cross_mid": r"cross $H{\approx}0.9$\,pp",
        "cross_strong": r"cross $H{\approx}1.8$\,pp",
        "cross_vstrong": r"cross $H{\approx}4.2$\,pp",
        "two_specialist": r"two strong specialists, $H{=}17.5$\,pp",
    }
    lines = [
        r"\renewcommand{\arraystretch}{0.95}",
        r"\setlength{\tabcolsep}{4pt}",
        r"\footnotesize",
        r"\begin{tabular}{@{}lcccccccc@{}}",
        r"\toprule",
        r" & \multicolumn{2}{c}{$R{=}3$} &"
        r" \multicolumn{2}{c}{$R{=}10$} & \multicolumn{2}{c}{$R{=}20$} &"
        r" abst. \\",
        r"\cmidrule(lr){2-3}\cmidrule(lr){4-5}\cmidrule(lr){6-7}"
        r"\cmidrule(lr){8-8}",
        r"regime & plug & v3 & plug & v3 & plug & v3 & $R{=}3$ \\",
        r"\midrule",
    ]
    for key, label in short.items():
        if label is None:
            continue
        c3 = cell(results, key, R=3)
        c10 = cell(results, key, R=10)
        c20 = cell(results, key, R=20)
        if c3 is None:
            continue
        s3p = c3["statistics"]["plugin_descriptive"]["support_rate"]
        s3v = c3["statistics"]["clone_calibrated_v3"]["support_rate"]
        a3 = c3["statistics"]["clone_calibrated_v3"]["abstain_rate"]
        def pair(c):
            if not c:
                return "---", "---"
            return (pct(c["statistics"]["plugin_descriptive"]["support_rate"]),
                    pct(c["statistics"]["clone_calibrated_v3"]["support_rate"]))
        s10p, s10v = pair(c10)
        s20p, s20v = pair(c20)
        lines.append(
            f"{label} & {pct(s3p)} & {pct(s3v)} & {s10p} & {s10v} & "
            f"{s20p} & {s20v} & {pct(a3)} \\\\")
    lines += [
        r"\bottomrule",
        r"\end{tabular}",
        "",
        r"{\scriptsize $^\dagger$Null ($H{=}0$): false-support \%, nominal "
        r"5\%; else power \%. $M{=}9,T{=}400$, $B{=}300$ at $R{=}3$ ($150$ "
        r"sweeps), 300 randomizations. Wilson intervals and the full "
        r"$M,T,R$, missingness grid in Appendix~\ref{app:diagnostics}.}",
    ]
    OUT.write_text("\n".join(lines) + "\n", encoding="utf-8")
    print(f"wrote {OUT}")


if __name__ == "__main__":
    main()
