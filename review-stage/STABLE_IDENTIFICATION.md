# A项稳定能力识别：先纠正比较对象，再做验证设计

状态：固定种群的识别检查已完成，**A仍not ready**。以下是精确构造与界的数学实现，不是新实验结果，也不是正式推断放行。

## 1. 为什么不能直接转为“固定策略后验证收益”

独立验证可以去掉使用同一执行挑选并评分的乐观偏差，但不能自动修正比较器选错的问题。设发现数据为D，逐题策略权重为w(D)，发现阶段选定固定成员为h_D。验证估计的是策略相对h_D的fresh价值。h_D可能不是概率意义上的最佳固定成员；该条件收益可以为正，而H_stable为零。

精确反例：两个题目上三个成员的正确率分别恒为0.2、0.8、0.5。一次有正概率发生的发现矩阵为bare=[1,1]、h1=[1,0]、h2=[0,1]。按当前统一并列规则，逐题策略在bare与当题另一个正确成员间均匀选择，固定成员选择bare。fresh策略准确率0.425，固定比较器0.2，收益+22.5 pp；真正最佳固定成员准确率0.8，H_stable=0。策略对真正最佳固定成员的差为−37.5 pp。

因此，上一轮建议的条件验证只能作为单独的策略效用目标。不能把其正收益改名为稳定互补或据此关闭A项科学问题。

## 2. 可检验的稳定提升空间下界

固定任务集、代码池与目标运行分布，并保留bare。令

\[
V(\pi)=\frac1n\sum_x\sum_h w_{h,x}p_{h,x},\qquad
W(P,\pi)=V(\pi)-\max_h\frac1n\sum_xp_{h,x}.
\]

逐题权重必须非负且和为1，且在独立验证前固定。因为逐题凸组合不超过最大值，

\[
W(P,\pi)\le H_{\rm stable}(P).
\]

验证数据应保留策略相对**每个**固定成员的配对差，而不是只减发现集选出的一个固定成员。`validation_differences`返回cell/group/block/member数组，整体执行块内保留全部任务相关性。只有对这些成员比较的同时有效下界为正时，才能把它用作该固定种群H_stable为正的证据。W可能为负，这不意味着H_stable为负。

这仍不证明真实种群超过dev-code clone，也不证明新增价值来自机制、可以推广至新数据库或满足相同计算预算。

## 3. 两个下界不能直接相减

另一个精确构造中，真实种群的所有p均为0.5，H_stable=0、策略witness为0。包含bare和同源码克隆的比较池为bare=[0.9,0.1]、两个相同代码成员均=[0.1,0.9]；其H_stable=0.4。错误发现策略可能逐题选中较差成员，fresh准确率0.1、witness=−0.4。

两个witness相减为+0.4，而真正H_stable差为−0.4。负下界截至零也不能使“下界减下界”成为差值下界。特别是保留不同bare的dev-code clone池并非纯同代码池，稳定提升空间不必为零。

若有同时有效的种群界[L_R,U_R]与[L_C,U_C]，差值界应为

\[
[L_R-U_C,\ U_R-L_C].
\]

平均cell时也按此方向配对平均，并要求覆盖事件同时涵盖所有cell/group。

## 4. 一个透明但很保守的直接基准

若每个p的联合概率带为[l,u]，则

\[
L_H=\max\{0,\operatorname{mean}_x\max_h l_{h,x}
-\max_h\operatorname{mean}_x u_{h,x}\},
\]
\[
U_H=\min\{1-1/K,\operatorname{mean}_x\max_h u_{h,x}
-\max_h\operatorname{mean}_x l_{h,x}\}.
\]

K包括bare；K=1时H恒为零。上界1−1/K来自最佳固定准确率至少为oracle准确率的1/K、oracle至多为1。代码处理数值舍入时保留非负性。

`hoeffding_bands`实现分布无关的保守参照：固定任务/代码下，每个坐标在R个**独立同分布时间块**的二元结果均值为p_hat，同时覆盖M个坐标的半径为

\[
\epsilon=\sqrt{\log(2M/\alpha)/(2R)}.
\]

块内各任务、成员和cell可任意相关；时间块之间的独立与运行分布稳定仍是外部前提，代码不能验证它们。缓存或provider漂移可能破坏前提。此处不是提出可实用的正式主估计器；generic带也未利用clone源码相同所隐含的概率等式。

4cell×3group×3member×180题对应M=6480，alpha=0.05时，仅作半径算术：

| 独立验证块R | 未裁剪概率半径epsilon |
|---:|---:|
| 4 | 1.2483 |
| 8 | 0.8827 |
| 16 | 0.6241 |
| 64 | 0.3121 |
| 256 | 0.1560 |
| 1024 | 0.0780 |

这些宽界说明该直接基准在少量重复下信息有限；不能从保守上界反推实际样本复杂度，不能据此直接批准增加到表中某个R。表格没有模拟观测数据或验证覆盖率。
