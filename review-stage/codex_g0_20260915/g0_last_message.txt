## Verdict

score: 4.5/10 ; verdict: not ready

## engineering_gate

The protocol is largely explicit and the four-state manifest is honest. I verified all archived `mean_calls` values against 400 rows per harness. The panel draw also recomputes correctly: using the literal `stratum` token selects `gsm_deepseek_s0_g3` as the deepseek pick, and sampling `atlarge` after removing the six stratum picks yields the recorded two at-large members.

Implementation is not yet protocol-safe. The existing collector defaults to the 300-task `task_split.json`, hardcodes `repeat: 0`, and calls the bridge directly. The newer MATH collector requires clone module IDs that do not exist, does not enforce the stated global concurrency, and does not bind the panel draw into its acquisition manifest.

## scientific_claims

The protocol correctly excludes repeat-0 from the repeat set, distinguishes clone provenance from statistical independence, freezes discovery on repeat 1 and validation on repeats 2–3, and prohibits treating plug-in headroom as stable complementarity.

The decision chain remains under-specified. “Significant” lacks a frozen α, exact test statistic, permutation count, null construction, and explicit handling of selection mapping and missing cells. Discovery and validation use the same tasks, so the protocol addresses repeat noise but does not provide task-level validation against task-specific selection.

The eligibility rule is label-blind for the new collection, but `n_llm_calls` is generated by response-dependent harness control flow. It is therefore not fully outcome-independent; the protocol should call this historical cost-based eligibility rather than a pure outcome-blind sample.

## budget_gate

The arithmetic is internally consistent:

- 21,795 real-pool calls + 10,800 clone calls + 5,449 dev calls = 38,044 projected logical calls.
- 10,800 clone calls equals 9 clone slots × 3 repeats × 400 tasks.

However, 38,044 logical calls with up to two retries could require 114,132 provider attempts, while the hard cap is 45,000. The runtime has no acquisition-wide attempt counter or cost ceiling; `dollar_cost` is always `None`. The prior pilot explicitly retained unknown account pricing and CNY reconciliation, so the required pilot-informed 95% cost projection is not present.

## ready/almost/not ready rationale

Not ready. The conceptual protocol is substantially improved, and the manifest/repeat/statistical boundaries are better than the prior state. Collection must remain blocked until the executor binds the actual MATH/clone runner, condition semantics, global attempt and cost accounting, and the complete statistical test specification.
